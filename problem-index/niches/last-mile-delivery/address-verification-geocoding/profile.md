# Address Verification & Geocoding

**Parent Industry:** [[industries/last-mile-delivery|Last-Mile Delivery]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Address verification providers validate, standardize, and geocode delivery addresses against postal reference files and their own delivery point data, resolving the incomplete and mistyped addresses that generate failed deliveries.

## Insight Function
**Size:** 40-200 data engineers, geocoding specialists, and reference data staff
**Output:** Validated and standardized addresses, geocodes and delivery point attributes, deliverability scoring
**Proprietary data:** Postal reference files enriched with proprietary delivery point research and observed correction patterns
**Clock:** Real-time validation at point of order
**Buyer:** VP of Data / Head of Product
