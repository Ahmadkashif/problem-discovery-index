# Last-Mile Network Design Consultancies

**Parent Industry:** [[industries/last-mile-delivery|Last-Mile Delivery]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory

## What They Do
Network design consultancies model where a shipper should place delivery stations, how territories should be drawn, and which mix of carriers and owned fleet serves a demand pattern at lowest cost.

## Insight Function
**Size:** 20-100 network modellers, operations researchers, and consultants
**Output:** Network design studies, facility siting, carrier mix modelling, cost-to-serve analysis
**Proprietary data:** Network models and cost structures across many client engagements
**Clock:** Capital planning and peak season readiness
**Buyer:** Practice leader
