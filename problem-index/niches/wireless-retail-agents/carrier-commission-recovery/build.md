# Disputes Filed Before the Window Closes

**Niche:** [[niches/wireless-retail-agents/carrier-commission-recovery/profile|Carrier Commission Recovery]]
**Industry:** [[industries/wireless-retail-agents|Wireless Retail Agents]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** Reconciliation tools find the short-paid lines; nobody turns them into evidence-backed disputes in each carrier's format before the deadline.
**Tags:** #large-language-models #random-forests #feature-engineering #evaluation-metrics #workflow-orchestration #revenue-impact #automation
**Contested on:** Every serious competitor in this niche (iQmetrix ReconcilePro, outsourced reconciliation services and spreadsheet-run back offices) is fighting to match every carrier statement line to the activation that earned it and file the dispute before the carrier's window closes, and whoever recovers the most short-paid dollars per month-end takes the dealer's reconciliation.

## The Problem
Finding an unmatched line is half the work. The dispute needs the right evidence (order, receipt, activation confirmation, plan clause), in the carrier's portal or template, inside a window that varies by carrier and payment type. Back offices triage by size and file what they can before month-end; the long tail expires.

## Why Nobody Has Built This
Dispute processes are carrier-specific and confidential, outcomes aren't shared between dealers, and reconciliation vendors have treated the dispute as the customer's job.

## What to Build
A dispute engine that takes every flagged line, predicts the probability the carrier will grant it from the dealer's own history of outcomes by carrier, code and evidence type, assembles the evidence package automatically, and files or queues it in priority order of expected recovery against days left in the window. It learns from each outcome.

## Target Customer
Controllers at chains with 50+ stores; outsourced reconciliation services as a channel to smaller dealers.

## Impact If Built
More recovered commission per month-end without extra staff. If ~1–3% of commission goes unrecovered today (estimate), a chain with ~$100M in commission (estimate) recovers seven figures a year.
