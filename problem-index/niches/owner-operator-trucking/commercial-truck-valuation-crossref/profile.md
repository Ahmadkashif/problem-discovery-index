# Commercial Truck Valuation Guides

**Parent Industry:** [[industries/owner-operator-trucking|Owner-Operator Trucking]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
Publish the residual and market values for Class 8 tractors and trailers that lenders size loans against, lessors book residuals on, insurers settle total losses at, and owner-operators buy and sell on. The truck is the owner-operator's entire balance sheet, and its value is set by a published guide.

## Insight Function
**Size:** 100-500 analysts and data operations staff across the guide publishers
**Output:** Wholesale and retail value guides, residual forecasts, depreciation curves by spec and vocation
**Proprietary data:** Auction and retail transaction histories by specification, joined to configuration detail no public source carries
**Clock:** Monthly guide publication and continuous auction feeds
**Buyer:** VP of Valuation Services / Chief Analytics Officer
