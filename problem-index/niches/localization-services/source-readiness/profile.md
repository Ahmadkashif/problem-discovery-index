# Source Readiness

**Parent Industry:** [[industries/localization-services|Localization Services]]
**Category:** 🟠 Low Digitized
**Contested on:** Every serious competitor in this niche is fighting to catch the defects that were created in the source content before they enter thirty language pipelines and multiply — and whoever checks the source takes the account.

## Profile
**Market Size:** ~$4B US
**Share of Parent Industry:** ~15% of category revenue
**Digital Adoption:** Low — unchecked
**Target Buyer:** Content and product leadership
**Automation Potential:** Very high — automated source checking

## What Makes This a Distinct Niche
Half the defects that surface as translation problems were created in the source content, and nobody checks the source before it enters the pipeline. Concatenated strings, hardcoded formats, idioms, missing context, text embedded in images, ambiguous pronouns, strings reused in different grammatical contexts — each generates queries, delays and defects in every target language simultaneously. The cost is multiplied by the number of languages and is attributed to translation.

## Current Tools & Gaps
A handoff process and a query channel. The gaps: no automated source checking; no localisation guidelines enforced at authoring; no context supplied with strings; no cost attribution back to source defects; and no feedback loop to the authors.
