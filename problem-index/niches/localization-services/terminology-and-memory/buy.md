# Master Data Management From Enterprise Data

**Industry:** [[industries/localization-services|Localization Services]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Enterprise data management built stewardship and survivorship rules for shared reference data, and translation memories accumulate forever.
**Tags:** #data-integration #compliance #evaluation-metrics #descriptive-statistics #automation #k-nearest-neighbors #word-embeddings #sets-and-logic
**Contested on:** Every serious competitor in this niche is fighting to keep the translation memory and glossary trustworthy, because once linguists stop trusting them they work around them and the assets decay unchecked — and whoever maintains them takes the account.

## The Problem
Master data management exists because shared reference data degrades without stewardship. It established the components: a data steward with ownership, survivorship rules deciding which of several conflicting values wins, quality scoring, deduplication, a retirement path, and measurement of downstream trust. Organisations run it because the alternative is reference data nobody believes. Translation memories and glossaries are shared reference data with no stewardship at all.

## What Already Exists
Data stewardship with named owners; survivorship rules for conflicting values; quality scoring and profiling; deduplication and merge processes; and lifecycle and retirement management.

## The Customization Gap
The adaptation is to linguistic content whose correctness is contextual. It requires: (1) values that are correct in one context and wrong in another, so survivorship cannot simply pick a winner and must preserve context — this is the substantive difference from any master data problem; (2) correctness that decays as the product and the brand voice change rather than as the record ages; (3) a steward who must be a linguist rather than a data professional; (4) assets owned by the client but maintained, if at all, by an agency; and (5) usage evidence available from the translation environment, which master data management would envy.

## Target Customer
Language service providers, enterprise localization teams, translation technology vendors, and data governance providers.

## Impact If Solved
Master data management built stewardship and survivorship because shared reference data degrades without it. Values that are right in one context and wrong in another is why survivorship must preserve context rather than pick a winner.
