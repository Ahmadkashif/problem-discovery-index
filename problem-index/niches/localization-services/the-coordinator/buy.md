# Critical Path Management From Programme Delivery

**Industry:** [[industries/localization-services|Localization Services]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Programme delivery forecasts the critical path and escalates early, and localization coordination chases by email.

**Contested on:** Every serious competitor in this niche is fighting to let one coordinator run a release through thirty language pipelines where any one of them can hold the launch — and whoever gives them that visibility takes the account.

## The Problem
Programme delivery has managed parallel workstreams with a common deadline for decades. Critical path analysis identifies which stream governs the date, float shows which have slack, early warning indicators trigger escalation before a slip, and a single dashboard shows the whole programme. Thirty parallel language pipelines converging on a launch is a textbook instance, and it is managed with a status spreadsheet and chase emails.

## What Already Exists
Critical path and float analysis; earned progress against plan; early warning indicators with escalation; unified programme dashboards; and resource levelling across parallel streams.

## The Customization Gap
The adaptation is to thirty near-identical parallel streams delivered by external parties across timezones. It requires: (1) every stream having equal criticality because the launch waits for all of them, so float is close to zero everywhere and the usual critical path insight does not apply — this is the substantive difference; (2) streams delivered by external vendors and freelancers with limited status visibility; (3) timezone spread making synchronous escalation impossible; (4) progress that is hard to measure mid-stream, since a half-translated file is not half done in any useful sense; and (5) query dependencies that block one stream on a decision affecting all of them.

## Target Customer
Language service providers and enterprise localization teams, operations leadership, translation management vendors, and programme tooling providers.

## Impact If Solved
Programme delivery forecasts the critical path and escalates early as standard practice. Thirty streams with no float, delivered by external parties across timezones, is what makes the usual critical path analysis unhelpful here.
