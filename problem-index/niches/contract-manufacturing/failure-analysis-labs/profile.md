# Component Failure Analysis Laboratories

**Parent Industry:** [[industries/contract-manufacturing|Contract Manufacturing]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Independent laboratories determine why a component or assembly failed — decapsulating parts, imaging solder joints, running cross-sections and elemental analysis — and issue the written finding that assigns responsibility between the component maker, the contract manufacturer, and the design. They also perform counterfeit detection on parts sourced outside authorized channels.

## Insight Function
**Size:** 30-150 failure analysts, materials scientists, and technicians
**Output:** Failure analysis reports, counterfeit determinations, root cause findings
**Proprietary data:** A failure signature library built across decades of analyses linking observed physical evidence to confirmed root causes
**Clock:** Production stoppages and warranty dispute timelines
**Buyer:** Laboratory Director / VP of Analytical Services
