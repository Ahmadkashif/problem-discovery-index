# Which Events Are Worth Doing

**Niche:** [[niches/developer-relations-agencies/event-economics/profile|Event & Programme Economics]]
**Industry:** [[industries/developer-relations-agencies|Developer Relations Agencies]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** A large budget is allocated annually by precedent and nobody has compared two events on anything.
**Tags:** #evaluation-metrics #revenue-impact #descriptive-statistics #confidence-intervals #optimization-fundamentals #causal-inference #data-integration #hypothesis-testing
**Contested on:** Every serious competitor in this niche is fighting to decide which conferences, workshops and sponsorships are worth doing, when the spend is substantial and nobody has compared one against another — and whoever prices them takes the account.

## The Problem
The event calendar is set by asking which conferences the company sponsored last year, which relationships exist, and where the advocates want to speak. Costs vary by an order of magnitude between events. Nothing compares the outcomes. A workshop with thirty engaged developers and a booth at a large conference with two thousand badge scans cost similar amounts and are recorded identically, and nobody knows which produced anything.

## Why Nobody Has Built This
Event outcomes share the general attribution problem. Sponsorship decisions are relationship-driven and partly political. The badge scan is the only artefact and it measures proximity rather than interest. And the annual cycle means a poor decision is repeated before it could be evaluated.

## What to Build
Compare events on a common basis and treat the calendar as an allocation. Define a comparable unit of outcome across event types — meaningful technical conversations, workshop completions, subsequent community joins, trial starts — which is the core and is what makes two very different events comparable at all. Record cost per event fully, including advocate time and travel, since staff time frequently exceeds the sponsorship fee and is never counted. Follow up on event contacts with a consistent method so the outcome is measurable rather than anecdotal. Compare the same event across years, which is a within-event comparison that avoids most confounding. Try alternatives deliberately rather than renewing by default, which is the only way the comparison set grows. Distinguish event types — a workshop, a booth, a talk and a hackathon do different things and should be judged differently. Model the advocate time as the scarce resource it is, since that rather than money is usually the binding constraint. Report the calendar as an allocation decision with alternatives, which is what turns a renewal into a choice. Accumulate across clients and years, which is an agency's advantage. And be willing to conclude that a well-liked event is not worth its cost, which is the finding the process is currently designed to avoid.

## Target Customer
Developer relations agencies and in-house programme functions, marketing leadership, event organisers and sponsors, and programme measurement providers.

## Impact If Built
A substantial budget is allocated by precedent and relationship, and two events an order of magnitude apart in cost are recorded identically. A comparable outcome unit with full cost turns a renewal into an allocation.
