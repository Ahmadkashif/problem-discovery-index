# Prior Authorization Automation Vendors

**Parent Industry:** [[industries/physical-therapy|Physical Therapy Practices]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Automate authorisation submission and status tracking between providers and payers, assembling clinical documentation against payer-specific criteria.

## Insight Function
**Size:** 100-600 clinical analysts, payer rule researchers, data scientists, and integration staff
**Output:** Payer rule libraries, automated submission and status tracking, denial prediction, documentation gap identification
**Proprietary data:** Payer criteria and their real behaviour — what actually gets approved, which differs from published policy — accumulated across submissions
**Clock:** Authorisation turnaround windows and visit schedules
**Buyer:** VP of Product / Chief Clinical Officer
