# Rehabilitation Coding & Documentation Content Publishers

**Parent Industry:** [[industries/physical-therapy|Physical Therapy Practices]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Publish the code sets, modifier rules, medical necessity criteria and documentation requirements that determine whether a therapy visit is paid — including the timed-code and supervision rules that make rehabilitation billing distinctively error-prone.

## Insight Function
**Size:** 200-800 coding specialists, clinical editors, and policy analysts
**Output:** Code set content and edits, payer policy summaries, documentation requirement guidance, compliance reference works
**Proprietary data:** Decades of curated coding interpretation and accumulated payer policy history, none of which exists in a single public source
**Clock:** Annual code set updates, quarterly edit releases, and continuous payer policy changes
**Buyer:** VP of Content / Chief Coding Officer
