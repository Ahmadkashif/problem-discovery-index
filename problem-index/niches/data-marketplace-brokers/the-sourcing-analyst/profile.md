# The Sourcing Analyst

**Parent Industry:** [[industries/data-marketplace-brokers|Data Marketplace Brokers]]
**Category:** Underserved Audience
**Contested on:** Every serious competitor in this niche is fighting to give the analyst a reusable evaluation harness instead of a quarter spent rebuilding one — and whoever does that takes the account, because the same comparison is being constructed from scratch in every firm in the market.

## Profile
**Market Size:** ~$310M US in loaded analyst cost
**Share of Parent Industry:** ~6% of category revenue equivalent
**Digital Adoption:** None — the same harness rebuilt every quarter
**Target Buyer:** Data sourcing teams and the functions that fund them
**Automation Potential:** Very High — the harness is generic

## What Makes This a Distinct Niche
The person who actually evaluates datasets is a sourcing analyst with a spreadsheet, a set of sample files and an internal benchmark they trust. Each evaluation means writing loading code for a new schema, computing overlap against the internal reference, checking field completeness, assessing freshness and assembling a comparison. They do this for every candidate in every category, every quarter. The work is generic — the same measurements against a different schema — and it is rebuilt from scratch each time because no product supplies it and every firm builds its own privately. They are the market's actual quality mechanism, operating with no tools.

## Current Tools & Gaps
Notebooks, spreadsheets, internal reference datasets and ad hoc scripts. The gaps: no reusable evaluation harness; no standard comparison format, so results are not comparable across evaluations or between analysts; no memory of prior evaluations, so a provider rejected two years ago is re-evaluated from scratch; no shared benchmark, so every firm's assessment is private and non-transferable; and no record of why a dataset was rejected, which is the most reusable output of the whole exercise.
