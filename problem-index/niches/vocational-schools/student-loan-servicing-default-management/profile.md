# Student Loan Servicing & Default Management

**Parent Industry:** [[industries/vocational-schools|Vocational Schools]]
**Category:** Insight Layer
**Value-Chain Position:** Payer & intermediary layer

## What They Do
Service the loans that pay for vocational education and manage borrowers through repayment, delinquency and default — and, on the school side, run the default prevention programmes that keep a school's cohort default rate below the threshold at which it loses eligibility.

## Insight Function
**Size:** 500-3,000 servicing analysts, default prevention specialists, data scientists, and compliance staff
**Output:** Repayment plan counselling and enrolment, delinquency outreach targeting, default risk scoring, cohort default rate forecasting and management, portfolio performance reporting
**Proprietary data:** Repayment behaviour joined to institution, programme, borrower characteristics and outcome across millions of borrowers
**Clock:** Delinquency and default milestone dates, and the cohort default rate measurement window
**Buyer:** Chief Analytics Officer / VP of Default Prevention
