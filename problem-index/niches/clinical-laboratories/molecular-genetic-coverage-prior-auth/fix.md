# The Test Run Before the Authorization Existed

**Niche:** [[niches/clinical-laboratories/molecular-genetic-coverage-prior-auth/profile|Molecular & Genetic Test Coverage and Prior Authorization]]
**Industry:** [[industries/clinical-laboratories|Clinical Laboratories]]
**Type:** Fix (Pain Point)
**One-liner:** The sample is sequenced on day two, the authorization request goes out on day nine, and the payer's retroactive window closed on day seven.
**Tags:** #workflow-orchestration #large-language-models #automation #revenue-impact #quick-win
**Contested on:** Every serious competitor in this niche is fighting to get each high-dollar molecular or genetic test paid, through authorization, Z-code, coverage evidence and appeal, and whoever collects on the highest share of tests performed takes the account.

## The Problem
Labs run urgent oncology and prenatal tests immediately and leave authorization to a separate team that works a queue. Some payers allow retroactive authorization only within a few days of the service; others not at all. Requests that start late are denied on timing, not on merit.

## Why It's Still Broken
Lab operations is measured on turnaround and reimbursement on collections, and the run happens before reimbursement sees the case. Retro-authorization windows differ by payer and change without notice, and live in staff memory and spreadsheets.

## What a Fix Looks Like
Start the authorization clock at accessioning. For every test needing authorization, open the request the same day, record each payer's retro window, and escalate cases approaching it. Give lab operations a hold option for low-urgency tests where the authorization is unlikely to arrive in time.

## Who Feels the Pain
Reimbursement staff writing off tests that were medically justified, patients who receive bills for them, and ordering clinicians whose patients complain.

## Impact If Fixed
Ending timing denials, which need no new evidence, recovers money on tests already performed. Each avoided denial on a $1,500 test is $1,500 (estimate); a lab losing 200 a month to timing recovers ~$3.6M a year.
