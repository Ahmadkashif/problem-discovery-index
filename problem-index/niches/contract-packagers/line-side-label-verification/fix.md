# The Code Check That Is a Clipboard Every Thirty Minutes

**Niche:** [[niches/contract-packagers/line-side-label-verification/profile|Line-Side Label Verification, Coding & Inspection]]
**Industry:** [[industries/contract-packagers|Contract Packagers]]
**Type:** Fix (Pain Point)
**One-liner:** On most hand-pack lines, the lot code and expiry are checked by pulling a unit every half hour and writing it on a form.
**Tags:** #cnns #object-detection #compliance #quick-win #worker-facing
**Contested on:** Every serious competitor in this niche is fighting to catch every wrong label, missing lot code and unreadable barcode at full line speed, and whoever reaches zero escapes with the fewest false rejects stopping the line takes the account.

## The Problem
Periodic sampling misses whatever happens between samples: a coder that runs out of ink, a date that rolls over at midnight, a roll of labels from the wrong lot. The form shows the check was done, not that every unit was right (interval is an estimate; it varies by client).

## Why It's Still Broken
Fixed verification on every hand-pack line is too expensive for a small packager, and nobody has made the cheap version easy.

## What a Fix Looks Like
A low-cost camera or a handheld scan at pack-out that reads every case or unit code, alerts on the first bad one, and fills the form automatically.

## Who Feels the Pain
Line leads and QA technicians doing the sampling; brands whose codes are wrong in the market.

## Impact If Fixed
Code errors caught on the first unit instead of the next sample, and the clipboard retired.
