# Test Engineering Service Houses

**Parent Industry:** [[industries/electronics-contract-mfg|Electronics Contract Manufacturing]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory

## What They Do
Independent test engineering firms develop the in-circuit and functional test fixtures and programmes that new products require before they can be built at volume. The Pass 1 analysis identifies test engineering as chronically under-resourced and a four-to-eight week compression point in every new product introduction; these firms are what manufacturers buy to relieve it.

## Insight Function
**Size:** 20-150 test engineers, fixture designers, and programme developers
**Output:** Test fixtures, test programmes, coverage analyses — the billable deliverable
**Proprietary data:** Accumulated test strategy and coverage decisions across hundreds of board designs; escape and field failure outcomes are usually not returned
**Clock:** New product introduction timelines, which are fixed and compressed
**Buyer:** Managing Director / Engineering Manager
