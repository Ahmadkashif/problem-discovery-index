# Pattern Extraction

**Parent Industry:** [[industries/saas-implementation-partners|SaaS Implementation Partners]]
**Category:** Contested Sub-Niche
**Contested on:** Every serious competitor in this niche is fighting to find out what hundreds of past implementations of the same platform actually have in common — and whoever extracts that takes the account.

## Profile
**Market Size:** ~$8B US
**Share of Parent Industry:** ~13% of category revenue
**Digital Adoption:** Very low — never attempted
**Target Buyer:** Delivery leadership
**Automation Potential:** Very high — mining over existing artefacts

## What Makes This a Distinct Niche
This half is analysis over material the firm already has. Configuration metadata, requirements documents, integration specifications and test scripts from hundreds of engagements, mined into abstracted patterns with the variations that actually occur. It produces an internal reference a consultant can consult mid-engagement, it requires nobody to fund a product, and it is valuable on its own — knowing what the firm typically builds is useful even if nothing is ever packaged.

## Current Tools & Gaps
Project folders, a few reference architectures and the memory of long-serving staff. The gaps: no extraction of configuration metadata across engagements; no comparable representation; no clustering into patterns; no record of variation; and no retrieval from a new engagement's requirements.
