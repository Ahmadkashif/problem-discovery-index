# Government Bid Tools Adapted to Cargo Preference Rules

**Niche:** [[niches/ocean-shipping-carriers/us-flag-preference-cargo/profile|US-Flag Preference Cargo Carriers]]
**Industry:** [[industries/ocean-shipping-carriers|Ocean Shipping Carriers]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Government-contracting platforms track federal opportunities and proposals; ocean cargo tenders run on maritime terms they do not model.
**Tags:** #large-language-models #feature-engineering #compliance #workflow-orchestration #automation
**Contested on:** Every serious competitor in this niche is fighting to have a cargo-preference-eligible US-flag ship available where government-impelled cargo loads, and whoever has a compliant ship inside the most tenders' loading windows takes the account.

## The Problem
Carriers bidding agency cargo use generic opportunity trackers or spreadsheets that do not understand laydays, load ports or vessel eligibility.

## What Already Exists
Federal opportunity and proposal tools (GovWin, GovSpend, SAM.gov alerts) and generic bid-management software.

## The Customization Gap
Ocean tenders need maritime fields — laycan, load and discharge ranges, cargo type, US-flag and preference eligibility, rate basis — and a link to the carrier's fleet schedule. Fair-and-reasonable rate rules require cost evidence in a set format. The customisation is a maritime tender model and fleet-schedule integration.

## Target Customer
Commercial teams at US-flag carriers already using a government-contracting tool.

## Impact If Solved
Suppose a carrier misses ~10% of the feasible tenders it sees today (estimate). A tracker that knows which ships can serve each opportunity recovers several of those cargoes a year.
