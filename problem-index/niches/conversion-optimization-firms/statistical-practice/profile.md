## What Makes This a Distinct Niche
This half is inside each experiment. Was it powered for the effect it claims, was the stopping rule fixed, were the segments specified in advance, was multiplicity handled. It is methodology a firm can fix unilaterally, it improves every test from the moment it is adopted, and it says nothing about whether the past year's reported wins were real — which is the sibling problem entirely.

## Current Tools & Gaps
A testing platform with a significance indicator and a dashboard refreshed continuously. The gaps: no power analysis at design time; no enforced stopping rule; no pre-specification of segments; no multiplicity correction; and a platform whose defaults encourage all of it.
