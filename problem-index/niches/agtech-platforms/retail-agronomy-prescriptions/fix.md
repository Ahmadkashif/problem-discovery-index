# The Recommendation Presented Without a Number

**Niche:** [[niches/agtech-platforms/retail-agronomy-prescriptions/profile|Retail Agronomy — Prescriptions With a Conflict Attached]]
**Industry:** [[industries/agtech-platforms|Agtech Platforms]]
**Type:** Fix (Pain Point)
**One-liner:** A grower is asked to spend a large sum on an input and is given an agronomic rationale rather than an expected return, so the decision is made on trust in the adviser instead of on arithmetic either party could check.
**Tags:** #descriptive-statistics #confidence-intervals #evaluation-metrics #hypothesis-testing #revenue-impact #compliance #quick-win #worker-facing
**Contested on:** Every serious competitor in retail agronomy software is fighting to make a recommendation credible when the adviser's employer sells the product — and whoever can evidence that a prescription paid for the grower takes the relationship.

## The Problem
The recommendation is a fungicide application at a particular growth stage, with an explanation about disease pressure and yield protection. The cost is known precisely. The expected benefit is described qualitatively. The grower decides on the strength of the relationship and the plausibility of the story. If the recommendation were expressed as an expected return per acre with a range, both parties could examine it — and the fact that it is not is the clearest expression of the credibility problem in this model, because a number invites a check and a narrative does not.

## Why It's Still Broken
Expressing an expected return requires an estimated effect size, which requires the outcome measurement this sub-niche is about, so the absence is partly circular. It is also professionally uncomfortable: an agronomist asked for a number must either produce one from published trial data that may not apply to this field, or admit the uncertainty, and the narrative form avoids the choice. And a number that turns out wrong is remembered in a way a narrative is not, which is a real disincentive for the person giving the advice.

## What a Fix Looks Like
Express every recommendation as an economic proposition with its uncertainty stated. Expected yield response from the best available evidence — published trials adjusted for local conditions initially, the retailer's own measured outcomes as they accumulate — against the input cost and the current commodity price, giving an expected return per acre with a range and a break-even yield response. Stating the break-even alone is a large improvement and requires no effect estimate at all: telling a grower that this application pays for itself at a two bushel response is a fact both parties can reason about. Record the recommendation with its stated expectation, which is what makes the outcome measurement meaningful later. And be explicit about the evidence class behind each number, distinguishing a locally measured effect from a published trial from a professional judgement — which is more honest than the current uniform presentation and is what a grower most wants to know.

## Who Feels the Pain
Growers making six-figure input decisions on narratives; agronomists whose good recommendations are discounted at the same rate as everyone's; and the retailer, whose agronomic investment cannot be shown to be worth anything.

## Impact If Fixed
Break-even framing costs nothing and immediately changes the quality of the conversation, since it converts a recommendation into a proposition the grower can evaluate against their own expectations. Recording the stated expectation is what makes the measurement loop in the build note possible, which makes this fix the necessary first step rather than a smaller version of the same thing.
