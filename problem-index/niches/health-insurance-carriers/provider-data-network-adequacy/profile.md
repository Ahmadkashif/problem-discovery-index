# Provider Data, Directories & Network Adequacy

**Parent Industry:** [[industries/health-insurance-carriers|Health Insurance Carriers]]
**Category:** Low Digitized
**Contested on:** Every serious competitor in this niche is fighting to keep each directory entry matching what the provider's office would say on the phone, within the No Surprises Act's 90-day verification cycle, and whoever's directory passes a regulator's secret-shopper sample with the fewest wrong listings takes the account.

## Profile
**Market Size:** ~$2.5B a year in provider data operations staff, roster processing, attestation and validation services, and network adequacy tools (estimate)
**Share of Parent Industry:** ~2% of carrier administrative spend (estimate)
**Digital Adoption:** Low — rosters arrive as emailed spreadsheets in each group's own layout, and verification runs on outbound phone calls
**Target Buyer:** VP of Provider Data Management / Network Operations
**Automation Potential:** High — roster mapping, reconciliation and outreach targeting are mechanical once identities are linked

## What Makes This a Distinct Niche
The provider record is the plan's least-controlled dataset and one of its most regulated. Directory accuracy is federally mandated through the No Surprises Act's 90-day verification and two-business-day update rules (recalled), and MA directories are reviewed by CMS. Medicaid MCOs face state secret-shopper surveys, and EQR network adequacy validation will report quantitative results from April 2028. Network adequacy filings rest on the same records. Yet the data is supplied by providers who gain nothing from keeping it current. The work is still run on spreadsheets and phone calls.

## Current Tools & Gaps
Plan MDM and core-admin provider modules, CAQH ProView attestation, Quest Analytics for adequacy, credentialing verification organisations, and outsourced directory validation (logged as [[niches/directory-and-list-publishers/provider-directory-validation-vendors/profile|🔍 Healthcare Provider Directory Validation Vendors]]). The gaps are roster ingestion that needs a person per group layout, no field-level trust model across sources, verification run on a fixed cycle rather than by likely error, and adequacy computed on contracted rather than active providers.
