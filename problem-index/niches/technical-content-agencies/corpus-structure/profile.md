# Corpus Structure & Disambiguation

**Parent Industry:** [[industries/technical-content-agencies|Technical Content Agencies]]
**Category:** Contested Sub-Niche
**Contested on:** Every serious competitor in this niche is fighting to write statements that stay true when extracted from their surroundings — and whoever establishes that craft takes the account.

## Profile
**Market Size:** ~$330M US
**Share of Parent Industry:** ~11% of category revenue
**Digital Adoption:** Very low — written for pages
**Target Buyer:** Documentation practice leadership
**Automation Potential:** High — structure checking and authoring support

## What Makes This a Distinct Niche
This half is craft and structure, inside the documentation team's own control. A statement that relies on the reader knowing which version's page they are on, or having read the prerequisites above, becomes wrong when lifted out. Writing so that every statement carries its own context, and structuring the corpus so meaning is machine-readable, is authoring work that improves the documentation for human readers too — and it can be done without anyone ever measuring what an assistant says.

## Current Tools & Gaps
Lightweight markup, a style guide and a site structure that carries the context. The gaps: no requirement that statements be self-contained; no machine-readable version and deprecation marking; no semantic structure distinguishing prerequisite from aside; no checks for context-dependent statements; and no authoring guidance for extraction.
