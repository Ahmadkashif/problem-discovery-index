**Category:** ⚡ Highly Automatable
**Contested on:** Every serious competitor in this niche is fighting to generate reference material from the source of truth rather than maintaining it by hand, and whoever makes that generation reliable takes the account.

## Profile
**Market Size:** ~$180M US
**Share of Parent Industry:** ~6% of category revenue
**Digital Adoption:** Medium — partial
**Target Buyer:** Documentation engineering
**Automation Potential:** Very high — generation from source

## What Makes This a Distinct Niche
Reference documentation — parameters, methods, endpoints, configuration options, error codes — is a projection of the product's own definitions and should never be written by hand. Much of it still is, or is generated by a pipeline somebody built that breaks when the source changes shape. It is the most mechanically derivable content in the corpus, it is large, and the effort spent maintaining it is effort not spent on the conceptual and procedural content that actually requires a writer.

## Current Tools & Gaps
A generator for some interfaces, hand-maintained tables for the rest, and a build that occasionally produces nothing. The gaps: no generation for every interface the product exposes; no enrichment of generated output with the prose it needs; no detection when generation silently produces less than before; no versioned reference; and no reconciliation between generated and hand-written material.
