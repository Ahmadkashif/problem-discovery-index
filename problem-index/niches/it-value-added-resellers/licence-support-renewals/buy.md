# Licence Optimisation Tools Pointed at the Reseller's Book

**Niche:** [[niches/it-value-added-resellers/licence-support-renewals/profile|Licence & Support Contract Renewals]]
**Industry:** [[industries/it-value-added-resellers|IT Distributors & Value-Added Resellers]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Licence-optimisation software already reconciles entitlements and usage for one enterprise; a reseller needs the same view across hundreds of customers' renewals.
**Tags:** #descriptive-statistics #feature-engineering #data-integration #compliance #automation
**Contested on:** Every serious competitor in this niche is fighting to renew each customer's expiring software licences, cloud subscriptions and hardware support contracts before the vendor's renewal date, and whoever renews the largest share of expiring contract value on time takes the account.

## The Problem
At renewal the reseller must know what each customer owns, uses and is entitled to, and how the vendor's new rules apply. That evidence sits in the customer's tenant and contracts.

## What Already Exists
Flexera, ServiceNow software asset management and CoreView for Microsoft 365, built for an enterprise's own IT and procurement team; distributor subscription consoles for resellers.

## The Customization Gap
The adaptation needs: multi-customer views keyed on renewal date rather than one estate; vendor programme rules (growth-margin eligibility, VMware core minimums, co-term policies) applied per customer; usage evidence turned into a right-sized renewal quote; and delegated access that customers will grant a reseller.

## Target Customer
Resellers and licensing specialists (SoftwareOne, Crayon and large VARs' software desks) that run renewals for hundreds of customers.

## Impact If Solved
Right-sized, evidence-backed renewal quotes shorten the cycle Microsoft says can take three months, and could cut late renewals by a third (estimate).
