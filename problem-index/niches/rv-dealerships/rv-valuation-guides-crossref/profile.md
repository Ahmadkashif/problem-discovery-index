# RV Valuation Guide Publishers

**Parent Industry:** [[industries/rv-dealerships|RV Dealerships]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
Publish the base values dealers appraise trade-ins against, lenders size loans on, and insurers settle total losses at. Pass 1 names this layer directly and names its limit: the guides provide base values and cannot account for the condition variables that decide an RV's real worth.

## Insight Function
**Size:** 100-500 analysts and data operations staff across the guide publishers
**Output:** Wholesale and retail value guides by make, model, year and floor plan, depreciation curves, residual forecasts
**Proprietary data:** Auction and retail transaction histories tied to configuration detail no public source carries
**Clock:** Monthly guide publication and continuous auction feeds
**Buyer:** VP of Valuation Services / Chief Analytics Officer
