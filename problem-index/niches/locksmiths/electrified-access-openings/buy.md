# Hardware Schedule Software Joined to the Access Point Schedule

**Niche:** [[niches/locksmiths/electrified-access-openings/profile|Electrified Hardware & Access-Ready Openings]]
**Industry:** [[industries/locksmiths|Locksmiths]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Door-hardware scheduling software already holds every opening's hardware set; it stops at the hinge, where the access-control design begins.
**Tags:** #large-language-models #data-integration #compliance #workflow-orchestration #automation
**Contested on:** Every serious competitor in this niche is fighting to deliver electrified locks, strikes and exit devices that work with the client's access-control system and still release for egress and fire alarm the day the door is commissioned, and whoever passes commissioning without a return visit takes the account.

## The Problem
Architectural hardware consultants and distributors prepare hardware schedules in dedicated software and issue them as submittals. Electrified items are listed as parts, with wiring left to a separate riser diagram. The locksmith installing them has to reconcile the two by hand.

## What Already Exists
Door-hardware specification and scheduling software used by hardware consultants and distributors, manufacturers' online configurators and wiring-diagram libraries, and integrators' access-control design tools that produce point schedules and riser diagrams.

## The Customization Gap
The extension needs an opening-level join. It would import the integrator's point schedule, and attach to each electrified opening the lock function, fail mode, power requirement and monitoring devices from the hardware schedule. It would flag code-driven requirements such as free egress, fire-alarm release and stair re-entry, and produce a per-door commissioning checklist the locksmith and integrator sign together. It must use the trades' own vocabulary, BHMA functions on one side and input and output points on the other, rather than a generic product list.

## Target Customer
Hardware distributors and consultants who already produce schedules, and the locksmith installers who receive them.

## Impact If Solved
One reconciled opening record that both trades work from, built inside software the hardware side already uses.
