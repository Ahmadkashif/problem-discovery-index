# Electrified Hardware & Access-Ready Openings

**Parent Industry:** [[industries/locksmiths|Locksmiths]]
**Category:** Contested Sub-Niche
**Contested on:** Every serious competitor in this niche is fighting to deliver electrified locks, strikes and exit devices that work with the client's access-control system and still release for egress and fire alarm the day the door is commissioned, and whoever passes commissioning without a return visit takes the account.

## Profile
**Market Size:** ~$350M a year of electrified hardware supply, installation and service by locksmith and door-hardware firms (estimate)
**Share of Parent Industry:** ~13% of 561622 receipts (estimate)
**Digital Adoption:** Medium — hardware schedules and wiring diagrams exist as drawings and PDFs, but door-by-door function, power and release logic are checked by hand on site
**Target Buyer:** Project manager at the security integrator or general contractor holding the Division 08 hardware scope; facility security director on retrofits
**Automation Potential:** Medium — schedule checking and commissioning tests can be scripted; installation is manual

## What Makes This a Distinct Niche
An access-controlled door needs two trades to agree. The locksmith or hardware installer fits the electric strike, electrified mortise lock or exit device, the power transfer hinge, the request-to-exit switch and the door position switch. The security integrator wires the reader and panel. The opening must stay locked when it should, release on a valid credential, and still let people out freely and release on fire alarm where the code requires it. Fail-safe and fail-secure choices, power supplies and fire-alarm interfaces are where projects fail commissioning. The credential side of this work, keeping cardholders in step with HR, belongs to [[niches/security-alarm-integrators/access-control-credential-lifecycle/profile|Access Control & Credential Lifecycle]] under Security Alarm Integrators. This niche is the physical opening that system controls.

## Current Tools & Gaps
Hardware-schedule software at distributors and manufacturers, riser and wiring diagrams in CAD or PDF, and manufacturers' specification and technical support teams. The gaps: no automated check that each door's hardware function, power, fail mode and fire-alarm release are consistent with the access-control point schedule, and no commissioning record per door.
