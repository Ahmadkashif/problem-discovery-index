# Key Code & Bitting Data Publishers

**Parent Industry:** [[industries/locksmiths|Locksmiths]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
Publishers of the reference data locksmiths use to cut keys by code: code-series lookups that translate a lock or vehicle key code into a bitting, key-blank cross-references across manufacturers, and the depth and spacing tables code machines need. They sell software subscriptions, key-blank directories and machine data cards, often bundled by key-blank and machine makers.

## Insight Function
**Size:** Small editorial and data teams compiling manufacturers' code series, under 10 per publisher (estimate)
**Output:** Code software, blank directories, machine data updates
**Proprietary data:** Compiled code series and cross-references across decades of locks and vehicles
**Clock:** New lock and vehicle releases
**Buyer:** Publisher owner or product manager at a key-blank maker
