# NASTF Vehicle Security Professional Registry

**Parent Industry:** [[industries/locksmiths|Locksmiths]]
**Category:** Insight Layer
**Value-Chain Position:** Association research arms

## What They Do
The National Automotive Service Task Force runs the Secure Data Release Model, through which automakers release key codes, immobilizer reset codes and security PINs to vetted locksmiths and technicians. The registry vets applicants: a $100 application, a criminal background check, licence and insurance documents, and a credential valid for two years. It requires a customer authorisation form for each transaction within five days, audits users, and suspends accounts linked to auto-theft reports from NICB or police. Automakers set their own access fees on top.

## Insight Function
**Size:** A registry manager and a small team of application and audit reviewers, under 10 analysts (estimate)
**Output:** Credentials, suspensions and audits; no published analysis
**Proprietary data:** Per-transaction authorisation records showing which credentialed user drew which vehicle's security data, when and on what proof of ownership
**Clock:** Registry renewal cycles it sets itself
**Buyer:** NASTF board and the participating automakers
