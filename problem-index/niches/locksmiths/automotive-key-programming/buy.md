# VIN Decoding Extended to the Exact Key Part

**Niche:** [[niches/locksmiths/automotive-key-programming/profile|Automotive Key Replacement & Programming]]
**Industry:** [[industries/locksmiths|Locksmiths]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** VIN decoders already turn seventeen characters into make, model, year and trim; none returns the one key or fob part and the programming method that vehicle actually needs.
**Tags:** #k-nearest-neighbors #feature-engineering #data-integration #automation #revenue-impact
**Contested on:** Every serious competitor in this niche is fighting to cut and program a working key on the first visit for any vehicle the dealer would quote days out, and whoever completes the most all-keys-lost jobs on site without a failed attempt takes the account.

## The Problem
For a given model year there may be several key and fob variants. They differ by transmitter frequency, chip type, button layout, blade profile and whether the car uses a proximity smart key or a remote-head key. Choosing the wrong one wastes the part and the trip. Locksmiths cross-reference supplier catalogues, FCC IDs printed on the customer's old key (if there is one) and forum posts.

## What Already Exists
VIN decoding services (including NHTSA's public decoder and commercial vehicle-data providers) return manufacturer attributes. Key and fob suppliers publish application guides by year, make and model. Programmer vendors publish coverage by model.

## The Customization Gap
The locksmith needs the decode carried down to the security system. That means mapping VIN patterns to immobilizer family, key part numbers, FCC IDs, chip and frequency. It should resolve ambiguity with questions the customer can answer on the phone (push-button start? how many buttons?) and link each part to the programming procedures and tools known to work. Return and failure data from suppliers and locksmiths should then refine the mapping where catalogues are wrong. The generic decoder stops at the trim level, and the locksmith's problem starts there.

## Target Customer
Automotive locksmiths and key suppliers; dealer service and auction key specialists.

## Impact If Solved
Fewer wrong parts and wasted trips, and a faster, more confident phone quote, which is how the locksmith beats the dealer.
