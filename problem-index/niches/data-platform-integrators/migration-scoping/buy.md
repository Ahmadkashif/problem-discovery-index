# Scope Rationalisation From Application Migration

**Industry:** [[industries/data-platform-integrators|Data Platform Integrators]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Application migration established that the first decision is what not to move, and data migrations move everything.
**Tags:** #data-integration #evaluation-metrics #graph-theory #optimization-fundamentals #descriptive-statistics #revenue-impact #compliance #confidence-intervals
**Contested on:** Every serious competitor in this niche is fighting to establish which of a decade's warehouse logic and four thousand reports actually needs to move — and whoever scopes that honestly takes the account.

## The Problem
Large-scale application migration established a disciplined first step: assess the estate and decide, per application, whether to retire, retain, replatform, refactor or replace. Retiring what nobody uses is the cheapest win available and is taken first. The framework is standard in cloud migration practice, taught and applied. Data platform migrations begin with an inventory and a translation plan and skip the decision entirely.

## What Already Exists
Disposition frameworks classifying each asset; usage and business criticality assessment; retirement as an explicit first option; wave planning by disposition; and business case modelling per option.

## The Customization Gap
The adaptation is to thousands of small interdependent assets rather than hundreds of applications. It requires: (1) assets that number in the thousands and depend on each other densely, so disposition must be computed rather than assessed in workshops — this is the substantive difference; (2) usage data that is complete and machine-readable, which application assessment usually lacks and which makes the analysis cheaper; (3) dependencies that are precise, so a used asset's requirements can be traced exactly; (4) a target platform priced by consumption, making carried inventory an ongoing cost rather than a one-off; and (5) a source platform that can often be kept read-only, removing much of the risk that drives carry-everything.

## Target Customer
Data platform integrators, client programme leadership, platform vendors, and migration tooling providers.

## Impact If Solved
Application migration made retirement the first disposition option and the cheapest win. Thousands of densely interdependent assets with complete usage data is what makes the data version computable rather than assessed.
