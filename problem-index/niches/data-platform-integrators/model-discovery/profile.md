# Model Layer Discovery

**Parent Industry:** [[industries/data-platform-integrators|Data Platform Integrators]]
**Category:** ⚡ Highly Automatable
**Contested on:** Every serious competitor in this niche is fighting to make an existing asset findable so nobody builds a duplicate, and whoever makes discovery work takes the account.

## Profile
**Market Size:** ~$1.1B US
**Share of Parent Industry:** ~6% of category revenue
**Digital Adoption:** Low — naming conventions
**Target Buyer:** Analytics engineering
**Automation Potential:** Very high — automated documentation and search

## What Makes This a Distinct Niche
Dashboards proliferate because building a new one is faster than finding the existing one, and the same is true of models. Discovery is the direct cause of duplication, and it fails for mundane reasons: descriptions are empty, naming conventions decayed, the catalogue was populated once at go-live, and search matches names rather than meaning. Every piece of documentation that would fix it can be generated from the code, the lineage and the usage.

## Current Tools & Gaps
A data catalogue populated at deployment, a naming convention document, and a search box. The gaps: no generated descriptions; no search by business meaning; no indication of which asset is current or authoritative; no documentation kept current with the code; and no discovery inside the tools people actually use.
