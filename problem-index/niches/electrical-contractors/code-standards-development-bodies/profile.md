# Electrical Code & Standards Development Bodies

**Parent Industry:** [[industries/electrical-contractors|Electrical Contractors]]
**Category:** Insight Layer
**Value-Chain Position:** Association research arms

## What They Do
The NFPA develops and publishes the National Electrical Code and several hundred related standards, running the technical committee process, adjudicating public inputs and comments, and issuing formal interpretations. States adopt the code into law, which makes the published document the legal basis of every electrical installation in the country. Revenue is code publication, licensing, and training.

## Insight Function
**Size:** 150-500 staff engineers, standards developers, editors, and technical services
**Output:** The code itself, formal interpretations, technical bulletins, training content — the publication is the revenue
**Proprietary data:** The complete code development record — every public input, committee deliberation, and rejected proposal across decades — plus the technical enquiry history showing where the code is ambiguous in practice
**Clock:** The three-year code cycle, with fixed input and comment deadlines, and state adoption timelines that follow
**Buyer:** VP of Standards Development / Chief Engineer
