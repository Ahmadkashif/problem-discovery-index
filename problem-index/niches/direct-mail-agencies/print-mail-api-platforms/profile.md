# Print-and-Mail API Platforms

**Parent Industry:** [[industries/direct-mail-agencies|Direct Mail Agencies]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Lob, PostGrid, Postalytics and similar platforms let software teams and marketers send letters and postcards by API or a self-serve app, routing jobs to print partners, applying address verification and returning tracking and response data. They sell per piece on top of platform subscriptions, from free developer tiers to enterprise contracts.

## Insight Function
**Size:** 10-40 data and analytics staff at the larger platforms (estimate)
**Output:** Delivery and response dashboards, in-home predictions, benchmark content for marketing
**Proprietary data:** Piece-level send, scan and response events across many senders — held as each customer's data under platform terms
**Clock:** Customers' triggered sends and campaign dates; USPS price changes
**Buyer:** VP of Data / Head of Product Analytics
