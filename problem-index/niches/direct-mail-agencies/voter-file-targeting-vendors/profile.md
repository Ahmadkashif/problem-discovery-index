# Voter File & Political Targeting Data Vendors

**Parent Industry:** [[industries/direct-mail-agencies|Direct Mail Agencies]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
Partisan and nonpartisan data vendors compile state voter files into national databases with vote history, append commercial and consumer data, and build support, turnout and persuasion scores that political mail programmes are selected from. Campaigns, parties, PACs and their mail consultants license files and scores by cycle. The natural home for this pocket is the queued political campaigns industry, which is not yet built; it is logged here because political mail is one of this industry's niches.

## Insight Function
**Size:** 20-150 data scientists, modellers and data engineers per vendor (estimate)
**Output:** Enhanced voter files, modelled scores, universe selections and post-election analyses
**Proprietary data:** Cleaned, matched voter files with vote history retained across cycles, including for voters later removed from state rolls, commercial appends, and an archive of past scores that can be graded against recorded turnout
**Clock:** Election Day, state ballot-mailing dates and early-voting windows, all fixed in law — a hard third-party deadline on every file delivery and model refresh
**Buyer:** Chief Data Officer / Head of Analytics at the vendor
