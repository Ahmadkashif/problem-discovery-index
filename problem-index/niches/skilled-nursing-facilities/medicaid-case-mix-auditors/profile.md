# State Medicaid Case-Mix & MDS Audit Contractors

**Parent Industry:** [[industries/skilled-nursing-facilities|Skilled Nursing Facilities]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory & valuation

## What They Do
State Medicaid agencies contract firms such as Myers and Stauffer, which reports case-mix rate-setting and audit work for 35+ states, to set nursing facility rates from cost reports and MDS case-mix. The same firms review samples of MDS records against supporting documentation and recalculate rates when coding is not supported. With the Optional State Assessment gone since 30 September 2025, they are rebuilding state systems around PDPM groupings.

## Insight Function
**Size:** 50-300 across rate-setting analysts, auditors and MDS review nurses (estimate); the rate and audit analysts alone exceed 10
**Output:** Facility rate calculations, case-mix index reports, MDS review findings and sanctions, state policy modelling
**Proprietary data:** Multi-year MDS review results and rate files across many states, held under state contracts
**Clock:** Quarterly case-mix picture dates and rate periods set by each state plan, which are the client state's own audit calendar
**Buyer:** Engagement leader for each state contract; the client is the state Medicaid agency
