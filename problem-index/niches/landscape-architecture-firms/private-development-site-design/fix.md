# Unpaid Redesign After Value Engineering

**Niche:** [[niches/landscape-architecture-firms/private-development-site-design/profile|Private Development Site Design]]
**Industry:** [[industries/landscape-architecture-firms|Landscape Architecture Firms]]
**Type:** Fix (Pain Point)
**One-liner:** When the GC's number comes in high, the landscape is cut first, and the landscape architect redraws the set and recomputes the code tables for no extra fee.
**Tags:** #large-language-models #feature-engineering #compliance #workflow-orchestration #automation
**Contested on:** Every serious competitor in this niche is fighting to design landscapes that survive the developer's value-engineering round — drawn to the installed cost the pro forma assumed while still passing landscape review — and whoever avoids unpaid VE redesign takes the developer's next project.

## The Problem
A VE list arrives as a spreadsheet from the GC: downsize trees from 3-inch to 2-inch caliper, swap pavers for broom-finish concrete, delete irrigation in some beds, simplify the amenity deck. The landscape architect must judge which cuts still meet the city's landscape code and the approved site plan, redraw the affected sheets, recompute the compliance tables and sometimes resubmit to the city — often in days, and often without an additional services agreement.

## Why It's Still Broken
Contracts lump VE into basic services; the designer has no fast way to show which cuts break code or approvals; and each round is handled as one-off email and markup.

## What a Fix Looks Like
A VE workspace that takes the GC's list, shows each item's code and approval consequences and its effect on the compliance tables, applies accepted changes to the model, and produces a change summary that supports an additional-services request where the scope grew.

## Who Feels the Pain
Project landscape architects working nights to turn VE sets around, principals absorbing the fee, and developers waiting on a resubmittal.

## Impact If Fixed
VE rounds measured in days rather than weeks, and a record of scope that lets firms get paid for redesign.
