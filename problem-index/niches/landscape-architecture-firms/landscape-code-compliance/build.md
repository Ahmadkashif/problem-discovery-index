**Contested on:** Every serious competitor in this niche is fighting to compute each jurisdiction's landscape requirements correctly from the live drawing so the set passes landscape review on the first submittal, and whoever covers the most jurisdictions accurately takes the account.

## The Problem
A firm working across a metropolitan region deals with twenty or thirty landscape ordinances, each amended on its own schedule. Interpretation lives with whoever last did a project in that city. A new hire reads the code from scratch, misses an amendment or a credit rule, and the set comes back.

## Why Nobody Has Built This
Zoning-analysis vendors model the provisions developers care about at acquisition — height, setbacks, density, parking — and leave landscape provisions out. Building-code compliance products focus on the building. Landscape provisions are local, varied and individually small.

## What to Build
A rule library extracted from municipal codes with language models and verified by landscape architects: each provision as a structured rule with its applicability, ratio, credits, exceptions and effective date; linked to the CAD objects that satisfy it; recalculated live; and annotated with reviewer comments that reveal how each city actually interprets it. Subscribers get alerts when an amendment changes an active project.

## Target Customer
Firms of 10–200 people with heavy private development work across many jurisdictions, and civil engineering firms that carry landscape scope.

## Impact If Built
First-submittal approval on landscape provisions becomes routine, and interpretation knowledge stops leaving with staff.
