# A Decade of Experiments Nobody Recorded

**Niche:** [[niches/product-design-studios/cross-engagement-evidence/profile|Cross-Engagement Design Evidence]]
**Industry:** [[industries/product-design-studios|Product Design Studios]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** A studio runs a continuous experiment in interface design and throws away the results at every handover.
**Tags:** #causal-inference #evaluation-metrics #confidence-intervals #data-integration #hypothesis-testing #descriptive-statistics #tacit-knowledge-ml #bayesian-inference
**Contested on:** Every serious competitor in this niche is fighting to turn a decade of engagements into evidence about what interface decisions actually do — and whoever accumulates that takes the account.

## The Problem
Every engagement tests something: whether removing a step raises completion, whether progressive disclosure reduces abandonment, whether a different onboarding shape improves activation. Across two hundred engagements a studio has run these tests many times, in different contexts, with real users and real outcomes. None of it is recorded in a comparable form, so the firm's design knowledge is a set of opinions and the same questions are argued from first principles every time.

## Why Nobody Has Built This
Nothing is comparable across engagements because nothing was measured the same way, or at all. Client confidentiality is assumed to block it, usually more broadly than it does. The studio has no research function. And the value accrues to the practice over years rather than to any project.

## What to Build
Structure the record so engagements become comparable, then synthesise across them. Record each engagement's design decisions, context and measured outcome in a structured, comparable form, which is the core and is worthless in year one and decisive in year five. Classify decisions in a shared vocabulary — step count, disclosure pattern, defaults, navigation model — so unlike projects can be compared on like dimensions. Capture the context that matters: audience, product type, task frequency, prior state, since a finding without context misleads. Synthesise across engagements to produce studio-level findings with their strength stated, which is the output that changes how the firm argues. Report effect sizes rather than directions, as a direction is an opinion and a size is evidence. Separate what is generalisable from what was client-specific, which is the judgement the synthesis turns on. Anonymise enough to use across clients, which is usually straightforward and rarely attempted. Make the corpus queryable by the designers who need it mid-project. Note where the evidence is thin rather than overclaiming, since a studio's credibility depends on the honest cases. And use the findings in proposals, which is where the accumulated evidence converts into revenue.

## Target Customer
Design studios and consultancy design arms, in-house design organisations, design education and professional bodies, and knowledge management vendors.

## Impact If Built
Two hundred engagements have tested the same questions repeatedly with real users and real outcomes, in no comparable form. A structured decision-and-outcome record turns a portfolio into evidence the firm can argue from.
