# Remediation Technology Vendors

**Parent Industry:** [[industries/environmental-consultants|Environmental Consultants]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Vendors supplying in-situ treatment reagents, thermal systems, and remediation equipment run technical groups that design applications, publish performance case studies, and support consultants selecting a remedy.

## Insight Function
**Size:** 20-100 remediation engineers and technical support staff
**Output:** Application designs, performance case studies, technical guidance
**Proprietary data:** Treatment performance across hundreds of site applications and geochemical conditions
**Clock:** Project schedules and remedial design milestones
**Buyer:** VP of Technology / Technical Director
