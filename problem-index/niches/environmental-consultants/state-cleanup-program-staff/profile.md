# State Site Remediation Programme Staff

**Parent Industry:** [[industries/environmental-consultants|Environmental Consultants]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
State environmental agency remediation staff review the investigation and cleanup reports consultants submit, set the standards sites must meet, and issue the closure determinations that release a property from further obligation. Their review is what every consulting deliverable is written for.

## Insight Function
**Size:** 30-200 project managers, geologists, and toxicologists per state programme
**Output:** Review comments, cleanup standards, closure determinations
**Proprietary data:** Complete site investigation and remediation records for every regulated site in the state, with outcomes
**Clock:** Statutory review timelines and programme reporting
**Buyer:** Programme director — public procurement
