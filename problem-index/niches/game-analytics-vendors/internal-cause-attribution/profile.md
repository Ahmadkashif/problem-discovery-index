# Internal Cause Attribution

**Parent Industry:** [[industries/game-analytics-vendors|Game Analytics Vendors]]
**Category:** Contested Sub-Niche
**Contested on:** Every serious competitor in this niche is fighting to establish which of a studio's own actions moved a metric, from data the studio already holds in four different systems — and whoever joins them takes the account.

## Profile
**Market Size:** ~$190M US
**Share of Parent Industry:** ~16% of category revenue
**Digital Adoption:** Very low — systems not joined
**Target Buyer:** Studio data leadership
**Automation Potential:** Very high — joining and attribution

## What Makes This a Distinct Niche
This half uses only the studio's own data. Build history, remote configuration changes, content releases, live event schedules and acquisition campaign changes all exist, in separate systems, unjoined to the metrics they move. Connecting them is an integration and causal inference problem the studio can solve alone, sold as tooling into the data platform, and it answers most of the question most of the time — without requiring anything from a vendor's cross-customer position.

## Current Tools & Gaps
An analytics platform, a build system, a config console, a content calendar and a campaign dashboard, none of which know about each other. The gaps: no unified change timeline; no attribution of movements to changes; no segment-level consistency checking; no composition versus behaviour decomposition; and no record of confirmed causes.
