# B2B Intent Data Cooperatives

**Parent Industry:** [[industries/directory-and-list-publishers|Directory & List Publishers]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
Cooperatives of B2B publishers and websites that pool content-consumption data and sell company-level "surge" scores showing which businesses are researching which topics; Bombora is the best-known. The scores are licensed to the sales intelligence platforms compiled by this industry and to marketing teams directly. Scored consistently with the consumer [[niches/direct-mail-agencies/direct-marketing-data-cooperatives/profile|🔍 Direct Marketing Data Cooperatives]] (48) except on labour and clock: an intent feed is a standard product, not a custom model per campaign, and no outside date governs it.

## Insight Function
**Size:** ~20-80 data scientists and topic-taxonomy analysts (estimate)
**Output:** Weekly company-by-topic intent scores and audience segments
**Proprietary data:** Pooled consumption records contributed by member publishers, resolved to companies — unavailable to any single publisher or compiler
**Clock:** None external; weekly release cadence set by the cooperative
**Buyer:** Chief Data Officer
