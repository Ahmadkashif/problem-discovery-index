# Tele-Research & Verification Call Outsourcers

**Parent Industry:** [[industries/directory-and-list-publishers|Directory & List Publishers]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Contact centres that run verification and data-collection calls for compilers and directory publishers on a per-call or per-record basis, in the US and offshore.

## Insight Function
**Size:** <10 analysts; callers are production staff
**Output:** Completed verification calls and updated records
**Proprietary data:** None — they work on the client's records
**Clock:** Client production targets
**Buyer:** Account director
