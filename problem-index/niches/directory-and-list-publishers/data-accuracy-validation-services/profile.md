# Data Accuracy Validation Services

**Parent Industry:** [[industries/directory-and-list-publishers|Directory & List Publishers]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory & valuation

## What They Do
Independent services that score how accurate data providers' records are against a truth set, so buyers can choose and sellers can prove; Truthset, which publishes quarterly 0-100% "Truthscores" per person and attribute with a collective of 20+ data providers, is the clearest example (vendor claims). Buyers are data purchasers and marketplaces; sellers pay to be rated.

## Insight Function
**Size:** ~10-40 data scientists and analysts (estimate)
**Output:** Accuracy scores and ratings for providers' records and attributes; validated audience segments
**Proprietary data:** A truth set assembled from multiple contributing providers and validation panels
**Clock:** None external; quarterly scoring cadence set by the service
**Buyer:** CEO / Head of Data Science
