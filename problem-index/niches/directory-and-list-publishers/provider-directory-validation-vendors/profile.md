# Healthcare Provider Directory Validation Vendors

**Parent Industry:** [[industries/directory-and-list-publishers|Directory & List Publishers]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
Firms that keep health plans' provider directories accurate: verifying each clinician's locations, phone numbers, network participation and whether they accept new patients, through outreach, attestation portals and data matching. Quest Analytics, CAQH and LexisNexis Risk Solutions are representative (named from recall). Plans pay because federal law requires them to verify directory information at least every 90 days and update it within two business days (No Surprises Act § 116), alongside Medicare Advantage directory reviews and state directory laws.

## Insight Function
**Size:** ~20-100 data and accuracy analysts (estimate), excluding outreach callers, who are production staff
**Output:** Verified provider directory records, accuracy reports and audit documentation for plans
**Proprietary data:** Cross-plan provider attestations and outreach outcomes — but largely built on plans' own rosters and on data providers submit for plans' use
**Clock:** No Surprises Act 90-day verification and two-business-day update windows; regulators' directory audits — deadlines that fall on the plan and pass through to the vendor
**Buyer:** VP of Provider Data / Chief Product Officer
