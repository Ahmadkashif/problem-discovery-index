# Survey Tools Pointed at an Edition Update Cycle

**Niche:** [[niches/directory-and-list-publishers/trade-and-professional-directories/profile|Trade, Professional & Membership Directories]]
**Industry:** [[industries/directory-and-list-publishers|Directory & List Publishers]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Survey platforms collect answers to questions; a directory needs each organisation to confirm its own record, field by field, with the right person signing off.
**Tags:** #large-language-models #evaluation-metrics #workflow-orchestration #data-integration #automation
**Contested on:** Every serious competitor in this niche is fighting to get the listed organisations to confirm their own entries every edition cycle at near-zero cost, and whoever publishes the highest share of entries verified this edition keeps the library and industry subscribers.

## The Problem
Editors run updates through generic forms, so every listee gets the same blank questionnaire and responses must be re-keyed and reconciled with the current entry.

## What Already Exists
Survey and form platforms (Qualtrics, SurveyMonkey, Typeform) with piped fields, reminders and response tracking.

## The Customization Gap
A directory needs: per-entry pre-fill from the current record; field-level change capture rather than free text; edition tracking (when was this entry last confirmed, by whom); respondent authority checks against the organisation's domain or registry; reminder logic that prioritises entries by importance and staleness; and direct write-back to the directory database with an editorial review queue.

## Target Customer
Small editorial teams at directory publishers already paying for a survey tool.

## Impact If Solved
The update cycle runs on existing software with directory logic layered on, instead of spreadsheets and re-keying.
