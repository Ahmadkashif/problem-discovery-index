# Data Append & File Enhancement

**Parent Industry:** [[industries/directory-and-list-publishers|Directory & List Publishers]]
**Category:** Highly Automatable
**Contested on:** Every serious competitor in this niche is fighting to append the most correct fields to a client's file — a match rate at a stated accuracy — and whoever proves the higher verified match rate on the client's own test file wins the job.

## Profile
**Market Size:** ~$500M US spend on appending compiled fields (phones, emails, firmographics, demographics, industry codes) to clients' customer and prospect files (estimate)
**Share of Parent Industry:** ~6% of the ~$8B US buyer spend on directories, lists and compiled business data, including directory advertising (estimate; see overview)
**Digital Adoption:** High — batch file processing and real-time append APIs
**Target Buyer:** Database marketing manager; CRM or data operations lead; nonprofit data manager
**Automation Potential:** Very high — matching and append are machine work; the open question is measured accuracy

## What Makes This a Distinct Niche
Here the compiler does not sell its own list; it matches its file to the client's and returns fields the client lacks — a phone for each donor, an email for each customer, an industry code and employee band for each account. Jobs are won on a test: the client sends a sample file, several compilers return appended samples, and the client compares match rates. The compiler's compiled file is the asset, but the client's file stays the client's, and appended data carries licence terms. Neighbouring work is covered elsewhere: merge/purge and address hygiene for mailings under [[niches/direct-mail-agencies/mail-file-data-processing/profile|Direct Mail Agencies: Mail File Data Processing]], and enrichment inside a customer data platform under [[niches/customer-data-platforms/profile-completeness-and-enrichment/profile|Customer Data Platforms: Profile Completeness & Enrichment]].

## Current Tools & Gaps
Batch append through compilers and service bureaus, real-time enrichment APIs, email and phone validation, and CRM connectors. Gaps: match rates are reported without accuracy, so a vendor that matches loosely wins the test; confidence per appended field is rarely delivered; and clients seldom measure accuracy after the fact, so the loose matcher keeps winning.
