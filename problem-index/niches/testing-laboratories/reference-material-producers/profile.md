# Reference Material Producers

**Parent Industry:** [[industries/testing-laboratories|Testing Laboratories]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Producers of certified reference materials and calibration standards that labs use to calibrate instruments and prove accuracy — NIST's standard reference materials, LGC, Merck's analytical standards, and specialist producers accredited to ISO 17034. Labs buy them per unit.

## Insight Function
**Size:** 20-200 chemists and characterisation scientists per producer (estimate)
**Output:** Certified materials with certificates of analysis and uncertainty
**Proprietary data:** Characterisation and stability study data behind each certified value
**Clock:** Material expiry and recertification; method changes that create demand for new materials
**Buyer:** Head of reference materials
