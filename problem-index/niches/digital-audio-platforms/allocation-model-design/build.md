# What Each Model Would Actually Pay

**Niche:** [[niches/digital-audio-platforms/allocation-model-design/profile|Allocation Model Design]]
**Industry:** [[industries/digital-audio-platforms|Digital Audio Platforms]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** The industry has argued about the allocation formula for a decade without anyone publishing what the alternatives would pay.
**Tags:** #monte-carlo-methods #descriptive-statistics #confidence-intervals #evaluation-metrics #revenue-impact #optimization-fundamentals #hypothesis-testing #compliance
**Contested on:** Every serious competitor in this niche is fighting to establish what each allocation model would actually pay each rights holder — and whoever computes and publishes it first moves an argument that has run on assertion for a decade.

## The Problem
User-centric allocation — each subscriber's fee divided among what that subscriber actually played — has been proposed, partially trialled and endlessly debated. Its effects are entirely computable: which artists gain, which lose, by how much, in which genres, at which catalogue sizes. So are the effects of minimum stream thresholds, minimum play durations and hybrid models. None of it is published, so the debate proceeds on anecdote and everyone's position reflects their interest rather than any evidence.

## Why Nobody Has Built This
Publishing the comparison names the winners and losers, so the party best placed to compute it is the party with the most to lose from the result — an analysis that would redistribute money is not commissioned by its likely losers. Licensing agreements restrict disclosure. Platforms would rather not be the venue for the argument. And no independent party has the data.

## What to Build
Compute every model and publish the distribution. Compute what each rights holder would receive under each candidate allocation over the same period, which is the core and is arithmetic rather than research. Report the distributional effects by artist size, genre, territory and catalogue age, since aggregate statements conceal exactly what the argument is about. Measure the effects of the threshold and duration policies that have already been introduced, because they reallocated real money and their impact was described rather than reported. Model the transition honestly, as a change creates losers and an analysis that ignores that will be dismissed. Include the interaction with fraud, since user-centric allocation changes the economics of manipulation substantially and that is a genuine argument for it. Model hybrid and partial approaches, because the realistic outcome is not a wholesale switch. Make the computation independently reproducible, which is what would give it authority. Report uncertainty from the parts that depend on assumptions, so the claims are defensible. Publish the methodology before the results, which builds credibility. And do it periodically, as the answer changes with listening behaviour.

## Target Customer
Executive, rights and policy leadership, artists and representative bodies, licensors, and regulators and researchers examining streaming economics.

## Impact If Built
An analysis that would redistribute money is not commissioned by its likely losers, which is why the comparison does not exist. It is arithmetic over existing logs, and publishing it converts a decade of positions into a set of numbers.
