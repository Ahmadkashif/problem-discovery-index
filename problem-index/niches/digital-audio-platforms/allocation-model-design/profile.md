# Allocation Model Design

**Parent Industry:** [[industries/digital-audio-platforms|Digital Audio Platforms]]
**Category:** Contested Sub-Niche
**Contested on:** Every serious competitor in this niche is fighting to establish what each allocation model would actually pay each rights holder — and whoever computes and publishes it first moves an argument that has run on assertion for a decade.

## Profile
**Market Size:** ~$2.7B US
**Share of Parent Industry:** ~15% of category revenue
**Digital Adoption:** Very Low — debated, never computed
**Target Buyer:** Executive, rights and policy leadership
**Automation Potential:** High — arithmetic over existing logs

## What Makes This a Distinct Niche
This contest is economics and policy. Pro-rata, user-centric, hybrid models, minimum thresholds, minimum play durations — each divides the same money differently, each has identifiable winners and losers, and the effect of each is computable from listening logs that already exist. The argument has been conducted for a decade with almost no published numbers, and it is settled by licensors, executives and regulators rather than by detection engineers.

## Current Tools & Gaps
A pro-rata calculation and policy changes announced with qualitative rationale. The gaps: alternatives never computed; distributional effects unpublished; threshold policy effects unmeasured; transition costs unmodelled; and no independent verification of any claim.
