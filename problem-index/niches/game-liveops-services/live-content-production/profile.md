# Live Content Production

**Parent Industry:** [[industries/game-liveops-services|Game LiveOps Services]]
**Category:** ⚡ Highly Automatable
**Contested on:** Every serious competitor in this niche is fighting to cut the cost of producing and shipping each event in a calendar that never has a gap — and whoever cuts it takes the account.

## Profile
**Market Size:** ~$200M US
**Share of Parent Industry:** ~7% of category revenue
**Digital Adoption:** Medium — manual pipeline
**Target Buyer:** Live team leads
**Automation Potential:** Very high — authoring, validation and rollout

## What Makes This a Distinct Niche
A live game ships events continuously — each with configuration, rewards, art, copy, localisation, schedule and a validation pass. The calendar has no gaps, so this production line runs permanently, and most of it is manual: a designer filling in a form, an engineer checking the numbers, someone staging it, someone else testing it. The unit cost of an event determines how much content a team can sustain, which makes it the direct lever on the cadence problem and the most mechanical work in the category.

## Current Tools & Gaps
A configuration console, a spreadsheet of rewards, a localisation process and a staging environment. The gaps: event definitions rebuilt rather than templated; no automated validation of reward and economy values; no preview of what players will see; manual localisation handoff; and no reuse across seasons.
