# Technical Reference Manual Maintenance

**Parent Industry:** [[industries/energy-auditors|Energy Auditors]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
Each state maintains a technical reference manual assigning deemed savings values to every efficiency measure — how much a given insulation upgrade or equipment replacement is credited with saving. Consultants and state agency staff research, negotiate, and update those values, and every rebate paid and every savings claim filed in the state is computed from them.

## Insight Function
**Size:** 10-50 engineers and analysts per state manual, across the consultancies maintaining them
**Output:** Deemed savings values, measure characterizations, manual updates
**Proprietary data:** Accumulated measure research and the evaluation findings that justify each value
**Clock:** Statutory manual update cycles that gate programme year savings claims
**Buyer:** State programme administrator / consulting practice lead
