# Software Licensing & Audit Defence Practices

**Parent Industry:** [[industries/it-managed-services|IT Managed Services]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory

## What They Do
Specialist practices determine an organization's effective licence position — what it has deployed against what it is entitled to — under publisher metrics that are deliberately complex, and defend it when Oracle, SAP, Microsoft, or IBM issues an audit notice. Findings routinely run into seven and eight figures, and the report is the entire engagement.

## Insight Function
**Size:** 50-500 licensing analysts, contract specialists, and technical consultants per major practice
**Output:** Effective licence position reports, audit responses and rebuttals, entitlement reconciliations, contract negotiation support
**Proprietary data:** An accumulated entitlement rule corpus — how each publisher's metrics actually work, which clauses have been enforced, which positions survived audit — plus the firm's own audit outcome history
**Clock:** Audit notices with fixed short response windows and enormous exposure
**Buyer:** Practice leader / Managing Director
