# Technology Due Diligence Practices

**Parent Industry:** [[industries/it-managed-services|IT Managed Services]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory

## What They Do
Technology diligence firms assess a target company's architecture, engineering organization, technical debt, and security posture for private equity buyers, on deal timelines measured in weeks.

## Insight Function
**Size:** 30-200 technologists, architects, and analysts
**Output:** Diligence reports, technical debt quantification, integration and remediation cost estimates, post-close roadmaps
**Proprietary data:** Assessment findings across hundreds of targets, matched in some cases to how the investments performed
**Clock:** Deal exclusivity periods, immovable
**Buyer:** Practice leader / Managing Director
