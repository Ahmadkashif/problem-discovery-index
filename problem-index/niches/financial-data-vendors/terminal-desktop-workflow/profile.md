# Terminal & Desktop Workflow

**Parent Industry:** [[industries/financial-data-vendors|Financial Data Vendors]]
**Category:** High Market Share
**Contested on:** Every serious competitor in this niche is fighting to be the surface where the analyst's model actually gets built — the Excel add-in, the API pull and the screen that feeds the memo — and whoever is embedded in that workflow keeps the seat when the client's market data office comes looking for cuts.

## Profile
**Market Size:** ~$6B
**Share of Parent Industry:** ~35% of the fundamentals, estimates, private-markets and reference segment
**Digital Adoption:** Very High — the product is software
**Target Buyer:** Head of desktop product; on the client side, the market data manager who signs the renewal
**Automation Potential:** High — the workflow around the data is still manual copy, paste and re-key

## What Makes This a Distinct Niche
The terminal is the seat licence — Bloomberg Terminal, FactSet Workstation, S&P Capital IQ Pro, LSEG Workspace, PitchBook's platform — and it is where the vendors' revenue is recognised. But the seat is renewed or cancelled on whether the analyst's real work runs through it: the Excel model refreshed by the add-in, the screen that produced the idea, the chart pasted into the investment memo. Clients' market data offices run annual cost reviews and cut the seats whose usage is shallow. The contest is therefore not the breadth of the data but the depth of embedding in a research workflow the vendor does not own.

## Current Tools & Gaps
Desktop applications, Excel and Office add-ins, Python and REST APIs, cloud data-warehouse delivery, and — since 2023 — LLM chat interfaces over the vendor's content. The gaps: the add-in pulls numbers but knows nothing about the model they feed; formulas break silently when a field definition changes; usage analytics measure logins rather than whether the data reached a deliverable; and the chat layer answers questions about the data without being able to show how each number was derived.
