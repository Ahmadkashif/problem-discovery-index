## The Problem
Researchers send surveys to GPs, call companies to confirm rounds, file and chase public records requests, and track who answered what. The cadence is quarterly and the response rate decides coverage.

## What Already Exists
Salesforce-class CRMs, sales engagement sequencing tools, survey platforms.

## The Customization Gap
Requests keyed to data fields rather than opportunities; per-jurisdiction public-records rules and response deadlines; modelling which contact will answer and when; drafting requests that reference what the counterparty disclosed last time; and closing the loop from response to extracted record.

## Target Customer
Private-markets research operations leaders.

## Impact If Solved
Response rate is coverage. Better-targeted, better-timed requests raise it without more researchers.
