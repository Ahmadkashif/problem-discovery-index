# Event Transcript & Call Content Producers

**Parent Industry:** [[industries/financial-data-vendors|Financial Data Vendors]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Transcript producers — FactSet CallStreet, LSEG StreetEvents, S&P's transcript unit, Bloomberg, and newer players such as Aiera and Quartr — capture and edit earnings calls and investor events and sell transcripts, audio and event data to vendors and investors.

## Insight Function
**Size:** 50-300 editors and event operations staff per producer
**Output:** Live and corrected transcripts, event calendars, speaker metadata
**Proprietary data:** Edited transcript archives aligned to machine drafts and audio
**Clock:** The earnings calendar; live events with near-real-time delivery
**Buyer:** Head of Transcripts / Event Content
