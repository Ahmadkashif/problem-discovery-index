# Enterprise Data Management With Event Semantics

**Niche:** [[niches/financial-data-vendors/reference-corporate-actions/profile|Reference & Corporate Actions Data]]
**Industry:** [[industries/financial-data-vendors|Financial Data Vendors]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Master data management matches records; corporate-actions reconciliation must understand which differences between feeds actually matter.
**Tags:** #gradient-boosting #feature-engineering #evaluation-metrics #data-integration #automation
**Contested on:** Every serious competitor in this niche is fighting to produce a golden copy of corporate actions and security identifiers that downstream systems can process without manual scrubbing — and whoever's events are right first time removes the client's reconciliation team.

## The Problem
Feeds differ on dates, rates and options; operators triage every difference.

## What Already Exists
Generic MDM and financial EDM platforms with rule-based matching.

## The Customization Gap
Learned triage of which discrepancies are material given the event type and the client's holdings, and which vendor is usually right for which market.

## Target Customer
Reference data teams at vendors, custodians and asset managers.

## Impact If Solved
Operators handle only discrepancies that matter.
