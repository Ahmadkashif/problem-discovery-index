## Profile
**Market Size:** ~$20M US
**Share of Parent Industry:** ~3% of category revenue
**Digital Adoption:** Medium — bespoke
**Target Buyer:** Research technology
**Automation Potential:** Very high — capture and synchronisation

## What Makes This a Distinct Niche
What a session leaves behind determines what the analysis can do with it. Currently that is a screen recording, an audio track, some notes in a document and, if anyone set it up, a telemetry log that is not aligned with any of them. Building a synchronised, timestamped, searchable record is a solved engineering problem in adjacent fields, it is set up bespoke per study here, and it is the precondition for every improvement in analysis.

## Current Tools & Gaps
Screen capture software, a microphone, a notes document and whatever build instrumentation the client happened to include. The gaps: no synchronised timeline; no telemetry capture by default; no in-session event marking; no searchable index; and no consistent setup across studies.
