## The Problem
Qualitative data analysis software is a mature category. It supports hierarchical coding schemes, rapid retrieval of coded segments, inter-rater agreement measurement, memo-writing, and increasingly automated first-pass coding. Academic and commercial researchers across many fields use it as standard. Games user research, which produces some of the richest qualitative material of any applied field, largely uses a video player and a spreadsheet.

## What Already Exists
Hierarchical coding schemes; coded segment retrieval and querying; inter-rater reliability measurement; memo and annotation systems; and automated first-pass coding suggestions.

## The Customization Gap
The adaptation is to synchronised gameplay, audio and telemetry rather than to text. It requires: (1) a timeline joining screen capture, think-aloud audio, facial or observer notes and game telemetry, where existing tools assume a transcript — this is the substantive difference and is why the category has not transferred; (2) behavioural events derived from game state as codeable objects alongside utterances; (3) game-specific context, since the same behaviour means different things in different genres; (4) turnaround measured in days rather than in months, requiring far more automation than academic practice assumes; and (5) findings that must be shown as video clips to a development team rather than quoted as text.

## Target Customer
Games user research firms, in-house research functions, playtesting platforms, and qualitative analysis software vendors.

## Impact If Solved
Qualitative analysis software is mature and widely used across research fields. A timeline joining gameplay, audio and telemetry, with a days-long turnaround, is what the existing category does not support.
