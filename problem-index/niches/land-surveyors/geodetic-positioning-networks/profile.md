# Geodetic Positioning Networks

**Parent Industry:** [[industries/land-surveyors|Land Surveyors]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Positioning network operators run the reference station infrastructure and correction services that give surveyors centimetre accuracy in the field, and maintain the coordinate reference frames everything is measured against.

## Insight Function
**Size:** 30-150 geodesists, network engineers, and data analysts
**Output:** Real-time correction streams, post-processing services, coordinate transformations, network integrity monitoring
**Proprietary data:** Continuous observation archives across dense station networks, plus the network solutions computed from them
**Clock:** Real-time field operations and reference frame update cycles
**Buyer:** VP of Positioning Services
