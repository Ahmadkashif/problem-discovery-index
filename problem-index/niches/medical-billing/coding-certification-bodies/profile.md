# Coding Certification Bodies

**Parent Industry:** [[industries/medical-billing|Medical Billing Services]]
**Category:** Insight Layer
**Value-Chain Position:** Association research arms

## What They Do
The coding certification bodies define the competencies medical coders are credentialed against, administer the examinations Pass 1 identifies in the workforce, and publish the practice guidance the profession works from.

## Insight Function
**Size:** 80-300 certification staff, psychometricians, coding experts, and content developers
**Output:** Certification examinations, competency frameworks, continuing education, coding guidance and publications
**Proprietary data:** Examination performance across hundreds of thousands of candidates, plus job analyses defining coder competence
**Clock:** Examination cycles, recertification, and annual code set changes
**Buyer:** VP of Certification / Chief Content Officer
