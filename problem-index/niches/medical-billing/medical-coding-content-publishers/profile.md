# Medical Coding Content Publishers

**Parent Industry:** [[industries/medical-billing|Medical Billing Services]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
The bodies that maintain the procedure and diagnosis code sets, and the publishers that annotate them, define the vocabulary every healthcare claim in the United States is written in. A code set is revised annually with fixed effective dates, and every payer system, provider system, and billing company in the country must implement the change on schedule.

## Insight Function
**Size:** 200-800 clinical coding experts, physicians, editors, taxonomists, and analysts
**Output:** Code set maintenance and annual revisions, coding guidelines and conventions, crosswalks, annotated references and decision support content
**Proprietary data:** The code set itself as a licensed standard with no substitute, plus decades of editorial interpretation, submitted change requests, and the reasoning behind every coding convention
**Clock:** Annual code set effective dates that the entire healthcare system implements simultaneously
**Buyer:** VP of Content / Chief Editorial Officer
