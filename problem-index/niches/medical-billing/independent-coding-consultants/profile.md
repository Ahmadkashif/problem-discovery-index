# Independent Coding Consultants

**Parent Industry:** [[industries/medical-billing|Medical Billing Services]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory

## What They Do
Individual certified coders consult on specialty coding questions, documentation improvement, and audit response, carrying deep knowledge of how a specialty's procedures should be coded and how particular payers behave.

## Insight Function
**Size:** 1-5 consultants, usually one
**Output:** Specialty coding guidance, documentation review, audit response support
**Proprietary data:** A career of payer behaviour and coding precedent, undocumented
**Clock:** Audit deadlines and annual code changes
**Buyer:** The consultant
