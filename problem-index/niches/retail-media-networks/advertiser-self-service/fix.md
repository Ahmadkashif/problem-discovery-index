# The Report That Arrives as a Spreadsheet

**Niche:** [[niches/retail-media-networks/advertiser-self-service/profile|Advertiser Self-Service]]
**Industry:** [[industries/retail-media-networks|Retail Media Networks]]
**Type:** Fix (Pain Point)
**One-liner:** Performance data arrives as a weekly export with a different schema per network, so the brand's analysis is a person retyping numbers rather than anything resembling analysis.
**Tags:** #data-integration #automation #workflow-orchestration #descriptive-statistics #evaluation-metrics #quick-win #worker-facing #compliance
**Contested on:** Every serious competitor in this niche is fighting to let a brand's media team plan, buy, optimise and report across a retail network without a spreadsheet and a phone call — and whoever does that gets the spend that currently goes wherever the paperwork is easiest.

## The Problem
Every Monday, eleven files arrive. Different column names, different date conventions, different product identifiers, different definitions of a conversion, different currencies of measurement for the same concept. Somebody spends most of a day turning them into one table. By the time the table exists the week is half gone, and the analysis it supports is a comparison of numbers that do not mean the same thing. The brand's retail media reporting is, in practice, a data entry function with a strategy job title attached, and the category's largest advertisers all maintain one.

## Why It's Still Broken
Networks export what their platform produces and treat the schema as an internal matter, which makes incompatibility a default rather than a choice anyone made. There is no industry standard for retail media reporting fields. Account managers supply a slide deck, which looks like service and prevents the underlying problem from being raised. And the manual work is absorbed by a brand-side analyst whose time nobody prices.

## What a Fix Looks Like
Deliver data rather than files. Provide programmatic access to performance data as the default, which is the fix and is a modest engineering task for any network that already has a reporting system — the export is a rendering of data that already exists in a queryable form. Publish a documented schema with explicit definitions for every metric, so the brand knows what a conversion means at each network rather than assuming. Adopt a common field standard through an industry body, since bilateral formats guarantee the current situation persists and no single brand can force convergence. Include product identifiers that map to the brand's own catalogue, which is the most expensive part of the reconciliation and is a matching problem the network is better placed to solve. Deliver at a useful frequency rather than weekly, since a week-old figure cannot support in-flight optimisation. State the measurement window and methodology in the data itself, so differences between networks are visible rather than silently averaged. Provide reconciliation totals so the brand can check completeness, which they currently cannot. Include the organic baseline alongside sponsored performance, which the retailer has and the brand needs for any incrementality view. Make historical restatements explicit when numbers change, because they do and silent revisions destroy trust. And measure the hours brands spend on reconciliation, because that figure is the most persuasive argument for fixing it and no network has ever asked.

## Who Feels the Pain
Brand analysts spending days retyping; networks whose performance is judged on numbers nobody can compare; and the category, whose reporting is a decade behind the spend it carries.

## Impact If Fixed
The export is a rendering of data already sitting in a queryable system, so programmatic access is a modest task. A documented schema with explicit metric definitions makes differences between networks visible instead of silently averaged.
