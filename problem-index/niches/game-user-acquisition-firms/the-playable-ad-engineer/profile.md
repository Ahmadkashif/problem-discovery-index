# The Playable Ad Engineer

**Parent Industry:** [[industries/game-user-acquisition-firms|Game User Acquisition Firms]]
**Category:** 🟣 Underserved Audience
**Contested on:** Every serious competitor in this niche is fighting to let one engineer build a complete small game to a five-megabyte budget in six network formats on a campaign deadline — and whoever makes that tractable takes the account.

## Profile
**Market Size:** ~$2.4B US
**Share of Parent Industry:** ~6% of category spend
**Digital Adoption:** Low — bespoke
**Target Buyer:** Creative engineering
**Automation Potential:** High — build pipeline and format targeting

## What Makes This a Distinct Niche
A playable ad is a complete small game built to a five-megabyte budget in six network-specific formats, and the brief is frequently to build something the actual product does not do. The engineer works under a size constraint that would be considered extreme in any other context, against a set of undocumented and inconsistent network requirements, on a campaign timeline, repeatedly. It is real game development treated as a creative asset, by people whose craft nobody has built tooling for.

## Current Tools & Gaps
A lightweight engine or hand-written code, a manual build process per network, and a size budget checked by looking. The gaps: no multi-format build pipeline; no automated size budgeting; no shared component library; no validation against each network's requirements; and no reuse across campaigns.
