# Evidence for the Conversation

**Niche:** [[niches/game-user-acquisition-firms/the-ua-manager/profile|The UA Manager]]
**Industry:** [[industries/game-user-acquisition-firms|Game User Acquisition Firms]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** The person held to the number controls the smaller half of it and has nothing to say about the larger half.
**Tags:** #worker-facing #causal-inference #evaluation-metrics #confidence-intervals #descriptive-statistics #revenue-impact #data-integration #hypothesis-testing
**Contested on:** Every serious competitor in this niche is fighting to give the person held to cohort payback some defence when payback is determined mostly by what another team ships — and whoever supplies that evidence takes the account.

## The Problem
A UA manager buys a cohort at a price justified by a predicted value. Over the next six months the game ships content of variable quality, runs events that work or do not, and changes monetisation. The cohort's realised value reflects all of it. The manager is reviewed on payback with no way to separate their own decisions from everything that happened afterwards, and the review consists of assertions on both sides.

## Why Nobody Has Built This
Separating the two effects requires data from a function that has no reason to supply it. Accountability structures are set by finance and have never been questioned. The manager has no standing to propose a change. And the industry's vocabulary treats payback as a UA number.

## What to Build
Give the manager a defensible decomposition, not an excuse. Report cohort payback alongside the content period effect estimated across all cohorts, which is the core — it makes visible what the manager did and did not influence without either side having to concede anything. Show the same source's cohorts across different content periods, since the contrast makes the point without argument. Forecast payback against the actual content roadmap rather than a flat assumption, which changes bidding decisions as well as reviews. Give the manager visibility of the content plan at bid time, as buying into a strong quarter and a weak one should not be priced identically. Measure the manager on the things they control — source mix, bid efficiency, creative performance, prediction accuracy — alongside the joint outcome. Provide the evidence in a form usable in a review rather than as an analysis project. Share the same numbers with the product side, because a decomposition used by only one party is a weapon rather than a measurement. Flag when a payback miss is attributable to content, which is frequently and is currently never said with evidence. Track the accuracy of the manager's own value predictions, which is a fair and available measure of their judgement. And propose the shared accountability structure the evidence supports, which is the durable fix.

## Target Customer
UA leadership and managers, mobile publishers, product leadership, and performance measurement vendors.

## Impact If Built
The person held to the number controls the smaller half of it and the review consists of assertions on both sides. A content period effect reported alongside payback makes the decomposition visible without either side conceding anything.
