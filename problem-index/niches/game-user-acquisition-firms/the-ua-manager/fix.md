# Answering for a Number Set Elsewhere

**Niche:** [[niches/game-user-acquisition-firms/the-ua-manager/profile|The UA Manager]]
**Industry:** [[industries/game-user-acquisition-firms|Game User Acquisition Firms]]
**Type:** Fix (Pain Point)
**One-liner:** Payback missed, the review asks what UA did wrong, and the season's content shipped late and thin.
**Tags:** #worker-facing #quick-win #descriptive-statistics #evaluation-metrics #confidence-intervals #revenue-impact #data-integration #workflow-orchestration
**Contested on:** Every serious competitor in this niche is fighting to give the person held to cohort payback some defence when payback is determined mostly by what another team ships — and whoever supplies that evidence takes the account.

## The Problem
The monthly review opens with payback against target. When it misses, the questions are about sources, bids and creative — the things UA controls. Frequently the actual cause is that the content shipped in that window was weak or late, which the UA manager knows, cannot demonstrate, and cannot raise without it sounding like an excuse. So the review produces changes to the controllable half in response to a problem in the uncontrollable half.

## Why It's Still Broken
The content history is not in the review — a conversation with only one side's data in the room will reach conclusions about that side, regardless of where the cause was. Raising it sounds defensive. Nobody has produced the comparison. And the structure of the review was never designed.

## What a Fix Looks Like
Put the content calendar in the review pack. Include the content and event calendar alongside the payback chart, which is the fix and requires no analysis at all to be immediately clarifying. Show payback for cohorts acquired in each content period, since the pattern is usually visible without any modelling. Compare the same source across strong and weak content windows, which is the most persuasive single chart available. Invite the product side to the review rather than reviewing UA alone, which changes the conversation structurally. Report the prediction accuracy of the UA team's own value model as a separate measure of their work. Agree in advance which factors will be treated as outside UA's control, so the discussion happens before there is a number to argue about. Track the content roadmap's delivery against plan, as slippage is a common and unexamined driver. Forecast payback with the roadmap included so targets are set realistically. Keep a record of past misses and their attributed causes, which prevents relitigating each time. And frame the whole thing as measurement rather than as defence, which is what makes it acceptable to both sides.

## Who Feels the Pain
UA managers answering for outcomes they did not cause; product teams who never hear about the payback consequences; publishers whose reviews change the wrong things; and the people who leave these roles.

## Impact If Fixed
A conversation with only one side's data in the room will reach conclusions about that side, regardless of where the cause was. Putting the content calendar next to the payback chart is clarifying before any analysis is done.
