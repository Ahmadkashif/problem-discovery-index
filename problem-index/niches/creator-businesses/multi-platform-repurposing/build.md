# Breaking the Linear Relationship

**Niche:** [[niches/creator-businesses/multi-platform-repurposing/profile|Multi-Platform Repurposing]]
**Industry:** [[industries/creator-businesses|Creator Businesses]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** Adding a platform adds a full production workload, so presence is capped by editing hours rather than by audience.
**Tags:** #transformers #cnns #seq2seq #automation #evaluation-metrics #workflow-orchestration #gradient-boosting #contrastive-learning
**Contested on:** Every serious competitor in this niche is fighting to make one piece of content become six without six times the work — and whoever breaks the linear relationship between platforms and production hours changes what a small team can cover.

## The Problem
The source material is one long piece. Each destination wants something different: a vertical cut with burned-in captions and a hook in the first second, a differently paced version for another feed, a still with a text overlay, an audio segment, a written summary. Each derivative is produced by an editor watching the source, choosing moments, reframing, captioning and exporting. Six platforms is six workflows, and the constraint on a creator's reach is how many hours their editor has.

## Why Nobody Has Built This
Clip tools generate derivatives mechanically without knowing what is good, so the output needs as much supervision as manual work — automation that produces candidates a human must fully review has not removed the work, only moved it. Platform conventions are tacit and change. Derivative performance is not fed back to the selection. And the editing market sells timeline tools rather than pipelines.

## What to Build
Select well, then adapt automatically. Select the moments worth clipping using the creator's own history of which derivatives performed, which is the core — the selection is the judgement and everything after it is mechanical. Model each platform's conventions explicitly — length, pacing, hook placement, caption style, aspect framing — so adaptation is a transformation rather than a re-edit. Reframe and track subjects automatically for vertical formats, since that is a solved vision problem and is still being done by hand. Generate captions and on-screen text in the creator's own style, as generic captioning is immediately recognisable and undermines the work. Produce a written derivative as well, because the text surfaces are frequently skipped entirely for want of time. Feed derivative performance back into selection, so the system learns which moments from this creator's content travel. Let the editor approve rather than produce, which is where the hours are recovered without losing quality. Plan coverage deliberately — which platform gets what and when — rather than posting everything everywhere. Preserve the creator's voice in every adaptation, since a derivative that sounds automated damages the brand it is promoting. And measure output per editor hour, which is the number that defines the constraint.

## Target Customer
Production leadership and editors, creators expanding platform presence, management companies, and editing and clip tool vendors whose output requires full review.

## Impact If Built
Automation that produces candidates a human must fully review has moved the work rather than removed it. Selecting moments from the creator's own derivative performance is the judgement step, and everything downstream of it is mechanical.
