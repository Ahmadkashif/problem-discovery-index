# Practice Management Scaled to One Licence

**Niche:** [[niches/architecture-firms/sole-practitioners-micro-firms/profile|Sole Practitioners & Micro-Firms]]
**Industry:** [[industries/architecture-firms|Architecture Firms]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** AEC practice software is built for firms with project managers and accountants; a sole practitioner needs proposals, phases and invoices in one evening a month.
**Tags:** #large-language-models #feature-engineering #automation #workflow-orchestration #quick-win
**Contested on:** Every serious competitor in this niche is fighting to give a one-person firm a second set of eyes on code and coordination before a set goes out, at a price a practice billing ~$150,000 per head can carry, and whoever does that inside the tools the architect already uses takes the account.

## The Problem
Small firms write proposals in Word, track time loosely, invoice from QuickBooks and lose track of what was in scope. The tools built for architecture practice assume staff, roles and overhead structures a one-person firm doesn't have.

## What Already Exists
Deltek Ajera, BQE CORE and Monograph for AEC project accounting; QuickBooks and FreshBooks generically; AIA contract documents for agreements.

## The Customization Gap
The adaptation needs: proposal and agreement drafting from AIA B105/B101 structures with phase fee splits suited to small projects; time capture by phase from the calendar and drawing software; invoicing by percent complete per phase; and an automatic flag when work drifts outside the agreed scope — packaged at a sole-practitioner price.

## Target Customer
Owner-architects of one- to five-person practices.

## Impact If Solved
An evening a month of admin instead of several, and scope creep caught when it starts.
