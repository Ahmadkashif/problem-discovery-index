# A Second Reviewer on Demand

**Niche:** [[niches/architecture-firms/sole-practitioners-micro-firms/profile|Sole Practitioners & Micro-Firms]]
**Industry:** [[industries/architecture-firms|Architecture Firms]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** Every larger firm has someone check the set before it goes out; a sole practitioner has nobody.
**Tags:** #large-language-models #cnns #object-detection #transformers #compliance #worker-facing #quick-win
**Contested on:** Every serious competitor in this niche is fighting to give a one-person firm a second set of eyes on code and coordination before a set goes out, at a price a practice billing ~$150,000 per head can carry, and whoever does that inside the tools the architect already uses takes the account.

## The Problem
A sole practitioner drawing a two-storey addition or a restaurant fit-out does the code analysis, the drawings and the specifications alone, then submits to a building department and waits. Errors — a missing guard height, an egress width that doesn't add up, a fire separation omitted at a garage — come back as corrections, or worse, get built.

## Why Nobody Has Built This
Drawing checkers are priced and pitched at mid-size firms with QA/QC budgets. Human peer review costs more than a small project can bear. Small residential and tenant-improvement work also runs on local amendments that generic checkers ignore.

## What to Build
A pay-per-set review service: upload the PDF set and project basics, get back a marked-up set within hours flagging code issues against the adopted local code, internal inconsistencies, and missing items the jurisdiction typically requires, with optional escalation to a licensed human reviewer for the flagged items only.

## Target Customer
Sole practitioners and firms of up to five people doing residential, small commercial and tenant-improvement work.

## Impact If Built
Fewer correction rounds, fewer field errors, and some of the protection a larger firm's QA/QC gives — at a per-project cost a small practice can absorb.
