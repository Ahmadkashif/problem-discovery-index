# Building & Fire Code Consultants

**Parent Industry:** [[industries/architecture-firms|Architecture Firms]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory & valuation

## What They Do
Code consulting firms are hired, usually by the architect or the owner, to interpret the building and fire codes for buildings the prescriptive code does not fit neatly: high-rises, atriums, laboratories, hospitals, assembly spaces, historic buildings, mass timber. They write the code analysis and code compliance reports, design performance-based alternatives (egress modelling, smoke control, fire modelling), negotiate them with the building official and fire marshal, and see them through permit and certificate of occupancy. Jensen Hughes — which describes code consulting as one of six service lines and cites 1,500 to 1,700 staff firm-wide — is the largest; regional code consultancies and the fire groups of large engineering firms make up the rest.

## Insight Function
**Size:** ~100-400 code consultants at the largest firm (its 1,500-1,700 headcount is firm-wide); 10-50 at regional firms (estimate)
**Output:** Code analysis reports, alternative means and methods requests, performance-based design reports, code modification requests, code peer reviews
**Proprietary data:** Every report the firm has submitted, joined to the authority's response — accepted, conditioned or rejected — by jurisdiction, reviewer office, code edition and approach; no other party sees acceptance decisions across jurisdictions
**Clock:** Permit plan review cycles and certificate-of-occupancy dates; code adoption cycles that change the base document every three years
**Buyer:** Chief technical officer / Head of code consulting practice
