# Code Analysis & Permit Set Preparation

**Parent Industry:** [[industries/architecture-firms|Architecture Firms]]
**Category:** Highly Automatable
**Contested on:** Every serious competitor in this niche is fighting to get a permit set approved on the first review cycle in a specific jurisdiction, and whoever knows that jurisdiction's amendments and examiner demands before submission takes the account.

## Profile
**Market Size:** ~$5B in fee value spent on code analysis, permit submission and correction responses (estimate, ~5% of billings)
**Share of Parent Industry:** ~5% (estimate)
**Digital Adoption:** Medium — codes searchable online and submissions electronic, but code analysis built by hand and correction responses written from scratch
**Target Buyer:** Project architect; permit coordinator; technical director
**Automation Potential:** High — occupancy, construction type, area, egress and fixture calculations are rule-based; local interpretation needs memory

## What Makes This a Distinct Niche
Every project needs a code analysis — occupancy classification, construction type, allowable height and area, occupant load, egress capacity and travel distances, fire-resistance ratings, plumbing fixture counts, accessibility — drawn up as code sheets and submitted with the permit set. Then come correction letters. The rules are written down, which makes the work automatable; the local amendments and examiner habits are not, which makes it a contest of jurisdictional memory.

## Current Tools & Gaps
ICC Digital Codes, UpCodes and its assistant, Revit schedules for areas and occupant loads, permit portals (ProjectDox, Accela, EnerGov), building-department pre-check tools such as Archistar and CivCheck. Gaps: code sheets assembled by hand from model data; correction history not reused; local amendments found late.
