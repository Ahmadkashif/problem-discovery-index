# Code Search With the Firm's Correction History

**Niche:** [[niches/architecture-firms/code-analysis-permit-sets/profile|Code Analysis & Permit Set Preparation]]
**Industry:** [[industries/architecture-firms|Architecture Firms]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Code search tools know what the code says; they don't know what this city's examiners asked the firm for last time.
**Tags:** #large-language-models #bert #k-nearest-neighbors #compliance #data-integration
**Contested on:** Every serious competitor in this niche is fighting to get a permit set approved on the first review cycle in a specific jurisdiction, and whoever knows that jurisdiction's amendments and examiner demands before submission takes the account.

## The Problem
Architects research codes in UpCodes or ICC Digital Codes and then learn from correction letters what the local building department actually enforces. That second body of knowledge never enters the research tool.

## What Already Exists
UpCodes (code search, local amendments, an AI assistant and Revit integration) and ICC Digital Codes (the official model code text and adopted state codes).

## The Customization Gap
The adaptation needs: the firm's correction letters and responses ingested as a private layer over the code text; comment history attached to the relevant code sections by jurisdiction; pre-submission checklists generated from that history for each new project; and permissions so the private layer stays inside the firm.

## Target Customer
Firms already licensing a code research tool that work across several jurisdictions.

## Impact If Solved
Code research that includes local practice, and fewer surprises in correction letters.
