# The Same Six Causes Every Month

**Niche:** [[niches/programmatic-ad-platforms/the-ad-operations-specialist/profile|The Ad Operations Specialist]]
**Industry:** [[industries/programmatic-ad-platforms|Programmatic Ad Platforms]]
**Type:** Fix (Pain Point)
**One-liner:** The discrepancy has the same handful of causes every time, nobody records which one it was, so the pattern that would let somebody fix it permanently never assembles.
**Tags:** #descriptive-statistics #evaluation-metrics #workflow-orchestration #quick-win #automation #hypothesis-testing #worker-facing #compliance
**Contested on:** Every serious competitor in this niche is fighting to explain the discrepancy between three systems automatically instead of having a person derive it every month — and whoever does that removes the most repeated unproductive task in the category.

## The Problem
Every ad operations specialist can list the causes: a tag placed below the fold that fires late, one system counting on request and another on render, viewability filtering applied in one report, a time zone offset, a geography exclusion, deduplication differences. They diagnose one of these every week. Nobody writes down which one it was. So there is no record showing that this particular publisher's tag placement causes a four percent gap every single month, which would justify a one-hour fix that would end it permanently. The knowledge is real, distributed across individuals, and never accumulates into anything.

## Why It's Still Broken
Discrepancy resolution is treated as a recurring task rather than as a defect with a root cause, which is the framing error — a task gets performed and a defect gets fixed. Contracts tolerate a threshold, so a persistent gap below it is never escalated. Nobody owns the cross-campaign pattern. And the specialist who knows is not asked and is measured on closing the current month.

## What a Fix Looks Like
Record the cause and let the pattern accumulate. Capture a structured cause code every time a discrepancy is resolved, which is the fix, takes one click, and is the step that converts individual knowledge into an organisational asset. Report cause frequency by publisher, platform, campaign type and creative format, which reveals within two months that a small number of specific configurations produce most of the gap. Attach the cost — the hours spent and the invoice value in dispute — since a recurring four percent gap with a number attached becomes a project and without one stays an annoyance. Escalate a repeating cause as a defect with a named owner rather than resolving it again, which is the whole point and is currently nobody's job. Fix at source where the cause is a placement or a configuration, since most are one-off changes that eliminate a monthly recurrence permanently. Feed known causes into trafficking checks so new campaigns do not reproduce them. Share the cause library across the team, because the knowledge is currently held individually and lost when people leave. Track discrepancy trend rather than only the monthly number, as a gap that is growing is a different situation from a stable one and the monthly view cannot tell them apart. Raise persistent partner-side causes commercially with the evidence, which is the only thing that moves a counterparty. And report total hours spent on discrepancy resolution, because until that figure exists nobody will fund removing it.

## Who Feels the Pain
Specialists diagnosing the same issue indefinitely; clients receiving explanations instead of correct numbers; and organisations paying repeatedly for work a one-hour fix would end.

## Impact If Fixed
Discrepancy is framed as a recurring task rather than a defect with a root cause, so it is performed rather than fixed. A one-click cause code turns individual knowledge into a pattern that names the specific configurations producing most of the gap.
