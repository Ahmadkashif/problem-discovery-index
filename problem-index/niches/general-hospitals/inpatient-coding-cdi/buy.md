# Outpatient Autonomous Coding Extended to Inpatient DRGs

**Niche:** [[niches/general-hospitals/inpatient-coding-cdi/profile|Inpatient Coding & Clinical Documentation Integrity]]
**Industry:** [[industries/general-hospitals|General Hospitals]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Autonomous coding works today for radiology, ED and clinic encounters; inpatient stays are longer, richer and paid on a grouper, so the product has to change shape.
**Tags:** #transformers #bert #large-language-models #evaluation-metrics #compliance #automation
**Contested on:** Every serious competitor in this niche is fighting to assign the DRG the documentation truly supports before the claim drops, and whoever captures the most legitimate severity with DRG shifts that survive payer audit takes the account.

## The Problem
Inpatient coders take ~20–40 minutes per chart (estimate), and coding backlogs hold up claims, so discharged-not-final-billed balances grow.

## What Already Exists
Autonomous coding vendors (Fathom, CodaMetrix, Nym and others, recalled) code high-volume outpatient encounters without human touch at stated confidence thresholds, and computer-assisted coding suggests codes for human review.

## The Customization Gap
Inpatient adaptation needs:

- reading a multi-day record with conflicting documentation;
- ICD-10-PCS procedure coding;
- applying Official Guidelines for principal diagnosis selection;
- POA indicators that drive HAC penalties;
- grouping to MS-DRG with the current year's grouper version;
- deciding when a query is needed rather than a code.

Confidence must be calibrated at the DRG level, not the code level, because one code error can change payment.

## Target Customer
HIM directors with coding backlogs and vendors extending outpatient products.

## Impact If Solved
Auto-finalising ~33% of inpatient charts (estimate) cuts discharged-not-final-billed days by ~1–2 (estimate). It also frees ~30% of coder hours for complex and audit-prone cases.
