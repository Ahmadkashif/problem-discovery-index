# Embroidery & Stitch Decoration

**Parent Industry:** [[industries/print-on-demand-platforms|Print on Demand Platforms]]
**Category:** Contested Sub-Niche
**Contested on:** Every serious competitor in this sub-niche is fighting to turn an arbitrary uploaded image into a stitch file that runs cleanly on a given fabric — and whoever does that takes the category, because digitising is a manual craft standing between a platform's automated pipeline and a physical result.

## Profile
**Market Size:** ~$600M US
**Share of Parent Industry:** ~10% of category revenue
**Digital Adoption:** Low — digitising is a manual craft
**Target Buyer:** Embroidery production operations
**Automation Potential:** High — stitch generation is a structured optimisation

## What Makes This a Distinct Niche
Embroidery takes an image and produces a stitch program: a sequence of stitch types, densities, underlays, directions and compensations that will sit correctly on a particular fabric. That conversion — digitising — is a skilled manual craft, and it determines everything. A poorly digitised file puckers the fabric, loses detail, breaks threads, misregisters colours and produces a stiff patch instead of decoration. It is also the one step in the platform's otherwise automated pipeline that is done by a person, at a cost and latency that sit uncomfortably in a business built on instant listing. The contest is automating that conversion well enough that an arbitrary uploaded design becomes a clean stitch file, which is a structured optimisation problem that has never had the data to be learned from until now.

## Current Tools & Gaps
Digitising software operated by skilled staff, thread colour matching, stabiliser selection, and machine-level parameters. The gaps: automatic digitising produces poor results and is used mainly as a starting point; artwork is not assessed for embroidery suitability before listing; fabric behaviour is not modelled into the compensation; thread colour matching to screen colour is approximate and unchecked; and no record connects digitising decisions to stitching outcomes.
