# Independent Fiduciaries for Annuity Provider Selection

**Parent Industry:** [[industries/pension-funds|Pension Funds]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory & valuation

## What They Do
Independent fiduciaries hired by corporate sponsors to select the insurer in a pension risk transfer, so that the choice meets DOL guidance on the safest available annuity and withstands the lawsuits that have followed some large transfers. They assess insurers' financial strength, investment portfolios and structure, and document the selection.

## Insight Function
**Size:** A few analysts per firm on PRT selection, inside broader fiduciary-services practices (estimate)
**Output:** Insurer assessment and selection reports per transaction
**Proprietary data:** Repeated assessments of the same set of PRT insurers
**Clock:** Transaction timetables set by the sponsor
**Buyer:** Practice leader
