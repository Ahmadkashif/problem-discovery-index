# Pension Administration System Vendors

**Parent Industry:** [[industries/pension-funds|Pension Funds]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Software firms that build and implement pension administration systems for public, multiemployer and corporate plans: Sagitec, Vitech (part of Majesco since 2026), LRS and others. They configure each plan's rules, convert its data and run the system under multi-year contracts such as Iowa's ~$60 million, ten-year path.

## Insight Function
**Size:** Business analysts and implementation consultants number in the hundreds at the larger vendors, but they configure rules and convert data (production work); no dedicated research function was found (estimate)
**Output:** Configured systems, conversions, upgrades
**Proprietary data:** Rule configurations across many plans; member data belongs to each client
**Clock:** Go-live dates in client contracts
**Buyer:** Head of Product
