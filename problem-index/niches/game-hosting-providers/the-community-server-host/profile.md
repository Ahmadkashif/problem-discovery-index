# The Community Server Host

**Parent Industry:** [[industries/game-hosting-providers|Game Hosting Providers]]
**Category:** 🟣 Underserved Audience
**Contested on:** Every serious competitor in this niche is fighting to let a person running game servers for a community do it without becoming an unpaid systems administrator — and whoever removes that burden takes the account.

## Profile
**Market Size:** ~$200M US
**Share of Parent Industry:** ~7% of category revenue
**Digital Adoption:** Very low — hobbyist
**Target Buyer:** Community hosts
**Automation Potential:** Very high — provisioning, updates and moderation

## What Makes This a Distinct Niche
A large tier of game hosting is community servers: a person renting boxes to run persistent worlds, modded servers and private matches for a group of players. They are not professionals, they carry real operational responsibility — updates, mods, backups, moderation, abuse, payments — and they are served by control panels designed fifteen years ago. Several titles depend substantially on this tier for their longevity, and nobody builds for the people running it.

## Current Tools & Gaps
A rented box, a web control panel, a mod manager and a chat server. The gaps: updates that break mods with no warning; no backup or rollback that a non-specialist can use; moderation tooling absent; no cost visibility or contribution collection; and no path to hand the server over when the host stops.
