# Food Truck Manufacturers & Upfitters

**Parent Industry:** [[industries/food-trucks|Food Trucks]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Builders design and equip mobile kitchens to menu requirements and to the health and fire code of the jurisdictions the operator intends to work in, producing the build specification the permit rests on.

## Insight Function
**Size:** 2-12 designers and technical staff per builder
**Output:** Build specifications, equipment layouts, code compliance documentation
**Proprietary data:** Accumulated jurisdiction build requirement knowledge
**Clock:** Build schedules and permit inspection dates
**Buyer:** Owner / Technical Director
