# FedRAMP Third-Party Assessment Organizations

**Parent Industry:** [[industries/cloud-infrastructure-consultants|Cloud Infrastructure Consultants]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
Accredited 3PAOs assess cloud service offerings against federal security requirements and produce the security assessment report that an authorizing official relies on to grant or deny authorization. Without it a cloud provider cannot sell to federal agencies, so the report gates a revenue stream.

## Insight Function
**Size:** 20-100 assessors, security engineers, and technical writers per firm
**Output:** Security assessment reports, control test results, remediation findings
**Proprietary data:** Accumulated assessment findings across cloud offerings and the record of which control implementations authorizing officials accepted
**Clock:** Authorization timelines and annual continuous monitoring deadlines
**Buyer:** Managing Director of Federal Assessment Services
