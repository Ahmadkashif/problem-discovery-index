# Control Framework & Certification Bodies

**Parent Industry:** [[industries/compliance-consulting|Compliance Consulting]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
HITRUST, the Unified Compliance Framework, and the Secure Controls Framework maintain the control catalogues and cross-framework mappings that let an organization satisfy many regulations with one control set. They license the framework and, in HITRUST's case, run the assurance programme certifying against it.

## Insight Function
**Size:** 100-400 framework analysts, standards researchers, and assurance staff
**Output:** Control catalogues, cross-framework mappings, certification decisions
**Proprietary data:** The mapping layer between hundreds of regulations and a normalized control set, maintained continuously, plus assessment results across certified organizations
**Clock:** Regulatory changes and annual certification cycles
**Buyer:** Chief Standards Officer / VP of Framework Development
