# Phone Number Reputation & Consent Data

**Parent Industry:** [[industries/collections-agencies|Collections Agencies]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
TransUnion's TRUST platform, Numeracle, and the branded calling and number reputation vendors track what happens to outbound calls — whether a number is labelled as spam, blocked by carriers, reassigned to a new subscriber, or covered by consent. Collection agencies buy it because a wrongly dialled reassigned number is a statutory damages claim and a spam-labelled number is a dead outbound programme.

## Insight Function
**Size:** 50-250 data analysts, telecom engineers, and compliance specialists
**Output:** Number reputation scores, reassignment and consent verification, deliverability analytics
**Proprietary data:** Carrier-sourced labelling and reassignment data joined to observed call outcomes across billions of attempts
**Clock:** Continuous — statutory liability attaches to each dial, and carrier labelling changes daily
**Buyer:** VP of Product / Chief Compliance Officer
