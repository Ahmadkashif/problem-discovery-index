# Codebase Assessment

**Parent Industry:** [[industries/game-porting-studios|Game Porting Studios]]
**Category:** Contested Sub-Niche
**Contested on:** Every serious competitor in this niche is fighting to measure the properties of an unfamiliar game codebase that determine how hard it will be to port — and whoever builds that scanner takes the account.

## Profile
**Market Size:** ~$300M US
**Share of Parent Industry:** ~15% of category revenue
**Digital Adoption:** Very low — reading code by hand
**Target Buyer:** Technical directors
**Automation Potential:** Very high — static analysis

## What Makes This a Distinct Niche
This half is a measurement problem over a single codebase. What is the renderer's structure, how much platform-specific code is buried in gameplay systems, how was the memory budget used, how far has the engine been modified, what does the build actually depend on. It is static analysis, it produces a report a technical director can read in an afternoon, and it is valuable on its own — a studio can use it to scope the work, plan the team and brief engineers, whether or not it ever changes how it prices.

## Current Tools & Gaps
A technical director reading source for a day, a demo build, and a questionnaire the client fills in. The gaps: no automated analysis of engine divergence; no measurement of platform-specific coupling; no memory or asset budget profile; no dependency and middleware inventory; and no comparison against past assessed projects.
