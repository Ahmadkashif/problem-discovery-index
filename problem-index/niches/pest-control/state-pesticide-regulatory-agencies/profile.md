# State Pesticide Regulatory Agencies

**Parent Industry:** [[industries/pest-control|Pest Control]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
Register pesticide products for sale within the state, license applicators, investigate misuse complaints and drift incidents, and enforce application record-keeping. Pass 1 names this as a heavy and state-by-state variable compliance burden.

## Insight Function
**Size:** 100-600 across the state programmes — registration reviewers, investigators, and analysts
**Output:** State registrations, applicator licensing, enforcement actions, misuse investigations, use reporting
**Proprietary data:** Application use reporting and complaint investigation records, held state by state and rarely comparable across them
**Clock:** Annual registration renewal and licensing cycles
**Buyer:** State programme director
