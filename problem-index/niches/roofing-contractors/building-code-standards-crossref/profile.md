# Roofing Code & Wind Load Standards Bodies

**Parent Industry:** [[industries/roofing-contractors|Roofing Contractors]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
Develop and publish the model building codes and structural load standards that determine how a roof must be attached, in what wind zone, with what fastening pattern — and the commentary and training the enforcement community works from.

## Insight Function
**Size:** 200-600 code development staff, technical committees, editors, and trainers
**Output:** Model codes and load standards, commentaries and interpretations, adoption tracking, inspector training
**Proprietary data:** Decades of code development record — proposals, testimony, committee reasoning and interpretation
**Clock:** Triennial code cycles and jurisdiction adoption calendars
**Buyer:** Chief Technical Officer / VP of Codes
