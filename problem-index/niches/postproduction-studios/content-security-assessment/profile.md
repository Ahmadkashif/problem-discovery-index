# Content Security Assessment (MPA Trusted Partner Network)

**Parent Industry:** [[industries/postproduction-studios|Postproduction Studios]]
**Category:** Insight Layer
**Value-Chain Position:** Association research arms

## What They Do
The MPA's Trusted Partner Network (TPN) sets content security best practices for vendors handling pre-release content and accredits third-party assessors who evaluate post facilities' sites, cloud and remote workflows. Results are shared with studio members through the TPN+ platform. TPN issues no pass or fail grade; studios read the findings and decide.

## Insight Function
**Size:** Small programme staff at TPN; assessors are independent firms and individuals (estimate)
**Output:** Best-practice documents, assessment questionnaires, assessment reports shared on TPN+
**Proprietary data:** Assessment findings across member vendors, visible to studios
**Clock:** Studio requirements for a current assessment before awarding work
**Buyer:** TPN programme lead; studio content security heads
