# Premium Large-Format Network Partners

**Parent Industry:** [[industries/movie-theaters|Movie Theaters]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
IMAX and Dolby Cinema supply premium auditoriums to exhibitors, usually on revenue-share or joint-venture terms, and program their networks: which films get the format, for how many weeks, and on which screens worldwide. AMC alone runs 224 IMAX and 181 Dolby Cinema screens. A few analysts at each firm track format performance by film and site to plan programming and new placements.

## Insight Function
**Size:** Under 10 network and box office analysts at IMAX, fewer at Dolby (estimate); film programming executives and exhibitor relations staff are not counted
**Output:** Network programming plans, site-placement cases for exhibitor partners, format performance reports to studios
**Proprietary data:** Global box office by premium screen and film, and placement outcomes by site
**Clock:** Studios' release dates and format windows
**Buyer:** Chief content or network executive
