# State Medicaid FQHC Rate-Setting & Audit Contractors

**Parent Industry:** [[industries/community-health-centers|Community Health Centers]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
State Medicaid agencies set and audit health centers' PPS rates, review change-in-scope requests and run wraparound reconciliations, often through contractors. Myers and Stauffer handles Indiana's change-in-scope requests (search summary) and similar work for other states (named from recall). States pay under procurement contracts.

## Insight Function
**Size:** Per-state engagements of a few auditors and analysts (estimate); per-center auditors are production
**Output:** Rate determinations, desk reviews and audits, reconciliation settlements
**Proprietary data:** Provider cost reports and state claims, held under the state contract
**Clock:** State plan and reconciliation timetables, the state client's clock
**Buyer:** State Medicaid reimbursement director
