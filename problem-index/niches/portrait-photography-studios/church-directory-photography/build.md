# A Sitting Calendar That Fills Itself

**Niche:** [[niches/portrait-photography-studios/church-directory-photography/profile|Church Directory Photography]]
**Industry:** [[industries/portrait-photography-studios|Portrait Photography Studios]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** A directory program's economics are set by how many households sit, and nobody predicts which households will book, show up or need a nudge.
**Tags:** #gradient-boosting #logistic-regression #large-language-models #evaluation-metrics #revenue-impact #workflow-orchestration
**Contested on:** Every serious competitor in this niche is fighting to fill a two-to-three-week sitting calendar with enough member households to make a free directory pay through portrait sales, and whoever does it without the sales pressure that gets them uninvited next cycle keeps the congregation.

## The Problem
The church announces sittings from the pulpit and in the bulletin; a volunteer works the phone list; slots fill unevenly, with Saturdays booked out and weekday evenings empty, and no-shows waste the photographer's time.

## Why Nobody Has Built This
Directory companies treat each church as a short campaign run by a volunteer; their tools are for scheduling and layout, not outreach. Member data sits in the church's own system.

## What to Build
Household-level outreach for the sitting window: import the member list (with the church's permission), predict which households are likely to book and when, send invitations and reminders in the channel each household uses, offer re-booking on no-show, and keep a live fill rate the coordinator can see. After the sitting window, members update their own entries so the directory stays current between editions.

## Target Customer
Directory program operators and the regional studios that photograph for them.

## Impact If Built
Fuller sitting calendars, fewer no-shows, more households in the directory, and more portrait sales without more pressure at the sitting.
