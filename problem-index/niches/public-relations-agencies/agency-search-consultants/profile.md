# PR Agency Search Consultants

**Parent Industry:** [[industries/public-relations-agencies|Public Relations Agencies]]
**Category:** Insight Layer
**Value-Chain Position:** Payer & intermediary layer

## What They Do
Intermediaries that run agency selection reviews for corporate communications departments: they write the brief, shortlist agencies, run pitches and benchmark fees. Some advertising search consultancies also handle PR reviews.

## Insight Function
**Size:** 2-10 consultants per firm (estimate)
**Output:** Agency shortlists, pitch management, fee benchmarks
**Proprietary data:** Agency credentials and fee data gathered from past reviews
**Clock:** The client's review timetable
**Buyer:** Founder
