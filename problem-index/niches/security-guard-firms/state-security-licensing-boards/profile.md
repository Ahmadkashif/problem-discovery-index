# State Security Licensing & Regulatory Boards

**Parent Industry:** [[industries/security-guard-firms|Security Guard Firms]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
License security officers and agencies, set training and firearms requirements, and investigate complaints and use-of-force incidents.

## Insight Function
**Size:** 10-60 per state — licensing, investigation, and compliance staff
**Output:** Licensure, training approval, complaint investigations, disciplinary actions
**Proprietary data:** Licensing and disciplinary histories, held state by state with no interstate exchange
**Clock:** Licence renewal cycles and complaint timelines
**Buyer:** Board executive
