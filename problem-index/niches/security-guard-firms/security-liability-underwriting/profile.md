# Security Contractor Liability Underwriting

**Parent Industry:** [[industries/security-guard-firms|Security Guard Firms]]
**Category:** Insight Layer
**Value-Chain Position:** Payer & intermediary layer

## What They Do
Underwrite the general liability, professional liability and workers' compensation programmes contract security firms carry, in a class where a single incident produces a very large loss.

## Insight Function
**Size:** 60-300 underwriters, actuaries, claims analysts, and loss control consultants
**Output:** Programme pricing and eligibility, claims analysis, loss control requirements, post-incident review
**Proprietary data:** Claims joined to post type, client industry, officer training and armed status — the empirical record of what security work actually produces losses
**Clock:** Annual policy renewals
**Buyer:** Chief Underwriting Officer
