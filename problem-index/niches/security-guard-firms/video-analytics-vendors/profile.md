# Video Analytics & Security Technology Vendors

**Parent Industry:** [[industries/security-guard-firms|Security Guard Firms]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Build the video analytics, access control intelligence and remote monitoring products increasingly sold as a substitute for guard hours, and the machine learning behind detection, classification and alerting.

## Insight Function
**Size:** 200-1,000 computer vision engineers, data scientists, and product researchers
**Output:** Detection and classification models, remote guarding services, alert triage, forensic search, occupancy and behaviour analytics
**Proprietary data:** Labelled video from deployed sites, with operator responses attached where remote monitoring is offered
**Clock:** Continuous monitoring, with no external deadline
**Buyer:** VP of Data Science / Chief Technology Officer
