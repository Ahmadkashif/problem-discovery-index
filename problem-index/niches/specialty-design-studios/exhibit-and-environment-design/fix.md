## The Problem
Graphics are the most revised part of any exhibit and the last to be finalised. Files move from client to designer to production artist to printer, with version names like FINAL_v3_revised. A panel printed from the wrong version, or to dimensions from an earlier drawing revision, is discovered at install.

## Why It's Still Broken
Graphic files and drawings live in different systems and are revised by different people. Nobody checks the print file list against the current drawing revision before files go to the printer.

## What a Fix Looks Like
A pre-print check that matches each print file to its panel in the current drawing, compares dimensions and bleed, detects whether the artwork matches the latest approved version, and blocks release of mismatches.

## Who Feels the Pain
Project managers on the show floor; production artists blamed for version errors; clients paying rush reprint fees.

## Impact If Fixed
Eliminates the most common, cheapest-to-prevent on-site failure in exhibit work.
