# Store-by-Store Variant Drawings From the Master Design

**Niche:** [[niches/specialty-design-studios/set-window-and-display-design/profile|Set, Window & Retail Display Design]]
**Industry:** [[industries/specialty-design-studios|Specialty Design Studios]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** A seasonal window is designed once and then redrawn by hand for every store window size in the chain.
**Tags:** #cnns #object-detection #feature-engineering #automation #workflow-orchestration #revenue-impact
**Contested on:** Every serious competitor in this niche is fighting to turn a concept into drawings that a fabricator can build and a crew can install right first time on a fixed date — across two hundred store windows or one shoot day — and whoever makes the design measurement-true to sites they cannot rehearse takes the account.

## The Problem
A retailer's windows vary in width, depth, height, glazing bars, floor level and lighting. The master design is approved for a flagship; a designer or drafter then adapts it to each window type, deciding what scales, what repeats and what is dropped. With dozens of window types, adaptation takes longer than the design and errors reach the fabrication shop.

## Why Nobody Has Built This
Window programmes are seasonal and bespoke to each retailer; the adaptation rules live in designers' heads, and no tool holds a reliable model of every store's windows.

## What to Build
A store-window library built from site photographs and scans, with each window's dimensions and obstructions; a parametric version of the master design whose elements carry adaptation rules (scale, repeat, anchor, drop); and automatic generation of per-store drawings, fabrication quantities and installation instructions, with exceptions flagged for a designer.

## Target Customer
Visual merchandising directors at specialty retailers and the display design studios that serve them.

## Impact If Built
Rollout drawings in days rather than weeks, fewer windows that do not fit, and fabrication quantities derived from the real estate rather than estimated.
