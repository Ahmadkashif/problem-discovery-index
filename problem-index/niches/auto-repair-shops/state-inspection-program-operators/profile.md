# State Vehicle Inspection Program Operators

**Parent Industry:** [[industries/auto-repair-shops|Auto Repair Shops]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
Opus Inspection, Applus+, and Gordon-Darby run entire state emissions and safety inspection programs under contract — the equipment in the shops, the data network, fraud detection, and the analysis reported to the state and to the EPA. Every inspection performed in a contracted state flows through their system.

## Insight Function
**Size:** 20-80 program analysts, data staff, and quality assurance engineers
**Output:** Program effectiveness reports, fraud detection findings, statutory analysis for the state and EPA
**Proprietary data:** The complete inspection record for a state — every test result, every failure, every retest — joined across years and to the shops that performed them
**Clock:** Statutory reporting deadlines and EPA State Implementation Plan obligations
**Buyer:** VP of Program Operations / Director of Analytics
