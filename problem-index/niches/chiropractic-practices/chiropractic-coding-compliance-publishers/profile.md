# Chiropractic Coding & Compliance Publishers

**Parent Industry:** [[industries/chiropractic-practices|Chiropractic Practices]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory

## What They Do
ChiroCode, KMC University, and similar publishers produce the coding manuals, documentation templates, and audit-readiness training chiropractors depend on to get paid and to survive payer audits. Content is updated annually against code set changes and payer policy.

## Insight Function
**Size:** 10-40 coding specialists, compliance analysts, and educators
**Output:** Coding manuals, documentation guidance, audit response training
**Proprietary data:** Accumulated payer audit findings and denial patterns collected from members
**Clock:** Annual code set updates and payer policy effective dates
**Buyer:** Publisher / Director of Content
