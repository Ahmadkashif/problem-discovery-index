# State Quality Rating System Administration

**Parent Industry:** [[industries/childcare-centers|Childcare Centers]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
States operate quality rating and improvement systems that observe, score, and publicly rate childcare programmes, usually through contracted assessors and university partners. The rating determines subsidy tier payments and parent-facing quality information, so the assessment is consequential for a provider's revenue.

## Insight Function
**Size:** 15-60 assessors, data staff, and evaluators per state system
**Output:** Programme quality ratings, observation scores, system evaluation reports
**Proprietary data:** Standardized classroom observation scores across every rated programme in a state, over years
**Clock:** Rating cycles and state plan reporting requirements
**Buyer:** State system administrator / evaluation contractor principal
