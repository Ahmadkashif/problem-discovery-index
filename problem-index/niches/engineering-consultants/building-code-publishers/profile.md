# Building Code Publishers

**Parent Industry:** [[industries/engineering-consultants|Engineering Consultants]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
The International Code Council develops and publishes the model building, structural, mechanical, plumbing, and energy codes that nearly every US jurisdiction adopts, runs the code development process, and sells the publications, commentaries, and certifications the design and enforcement professions depend on. Jurisdictions then adopt with local amendments, which is where the Pass 1 analysis locates one of the industry's chronic manual burdens.

This is the same organizational shape as the electrical code body indexed under `electrical-contractors`, in a different technical discipline — the recurrence is itself the finding — but the gap below is specific to this one.

## Insight Function
**Size:** 200-600 staff engineers, code developers, editors, and certification staff
**Output:** Model codes, commentaries, evaluation reports, certification programmes — the publication is the revenue
**Proprietary data:** The code development record across cycles, the product evaluation report library, and the accumulated technical opinion archive
**Clock:** The three-year code cycle with fixed development deadlines, followed by jurisdiction adoption
**Buyer:** VP of Codes / Chief Technical Officer
