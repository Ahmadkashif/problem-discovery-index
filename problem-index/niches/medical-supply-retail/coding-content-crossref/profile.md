# Medical Coding Content Publishers

**Parent Industry:** [[industries/medical-supply-retail|Medical Supply Retail]]
**Category:** Insight Layer

## What They Do
The code set maintainers and coding publishers define the equipment coding vocabulary every DME claim is written in, and publish the coverage and documentation guidance suppliers bill against.

## Insight Function
**Size:** 200-800 coding experts, clinicians, editors, and analysts
**Output:** Code set maintenance, coding guidelines, coverage and documentation references
**Proprietary data:** The code set as a licensed standard plus decades of editorial interpretation
**Clock:** Annual code set effective dates
**Buyer:** VP of Content
