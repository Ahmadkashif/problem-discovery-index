# DME Prior Authorization Services

**Parent Industry:** [[industries/medical-supply-retail|Medical Supply Retail]]
**Category:** Insight Layer
**Value-Chain Position:** Payer & intermediary layer

## What They Do
Outsourced prior authorization operations assemble the clinical documentation payers require before equipment can be supplied — the manual, paper-driven work Pass 1 identifies as the industry's dominant burden.

## Insight Function
**Size:** 100-800 authorization specialists, clinical reviewers, and analysts
**Output:** Authorization submissions and appeals, documentation gap analysis, denial pattern reporting
**Proprietary data:** Authorization requests joined to payer determinations across many suppliers and equipment categories
**Clock:** Delivery commitments and payer response windows
**Buyer:** COO / VP of Operations
