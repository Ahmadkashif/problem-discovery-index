# State Death Registration Systems

**Parent Industry:** [[industries/funeral-homes|Funeral Homes]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
State vital records offices operate the electronic death registration systems funeral directors, physicians, and medical examiners file into, issue certified death certificates, and supply mortality data to federal statistics and to permitted data users.

## Insight Function
**Size:** 20-100 registrars, analysts, and system staff per state
**Output:** Registered death records, certified certificates, mortality statistics
**Proprietary data:** The authoritative death record for the state, with cause and demographic detail no commercial compiler holds
**Clock:** Statutory filing deadlines measured in days after death
**Buyer:** State registrar — public procurement
