# Security Ratings Providers

**Parent Industry:** [[industries/cybersecurity-mssp|Cybersecurity MSSPs]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
BitSight, SecurityScorecard, and Panorays observe organizations from the outside — internet-facing configuration, certificate hygiene, botnet and malware signals, breach disclosures — and publish a security rating. Insurers price on it, enterprises gate vendors on it, and boards report it. The rated organization is usually not the customer, which is what makes the rating consequential and contested.

## Insight Function
**Size:** 100-500 data scientists, security researchers, and analysts
**Output:** Security ratings, risk analytics, vendor portfolio monitoring — the licensed product
**Proprietary data:** Longitudinal internet-scale observation joined to disclosed breach outcomes, plus the attribution work mapping observed infrastructure to the organizations that own it
**Clock:** Continuous; no third-party deadline governs publication
**Buyer:** Chief Data Officer / VP of Research
