# Virtual CISO & Security Programme Advisory

**Parent Industry:** [[industries/cybersecurity-mssp|Cybersecurity MSSPs]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory

## What They Do
Advisory practices provide fractional security leadership to organizations too small for a full-time CISO — running risk assessments, building programme roadmaps, and producing the board and customer-facing security documentation that increasingly gates enterprise sales.

## Insight Function
**Size:** 10-80 advisors, risk analysts, and technical writers
**Output:** Risk assessments, programme roadmaps, board reporting, customer assurance documentation
**Proprietary data:** Assessment findings across a client base, largely client-owned
**Clock:** Customer security review deadlines and audit cycles
**Buyer:** Practice leader / Managing Director
