# Penetration Testing Firms

**Parent Industry:** [[industries/cybersecurity-mssp|Cybersecurity MSSPs]]
**Category:** Insight Layer
**Value-Chain Position:** Specialist advisory

## What They Do
Offensive security firms attempt to break into client environments under contract and deliver a written report of what they found and how. Compliance frameworks require annual testing, so the report is both a security artefact and a compliance one, and it is the entire deliverable.

## Insight Function
**Size:** 50-500 penetration testers, red teamers, and report writers
**Output:** Penetration test reports, finding write-ups, remediation guidance
**Proprietary data:** Finding patterns across hundreds of client environments — which weaknesses recur, which exploit chains work, which controls actually stop them
**Clock:** Compliance-driven annual testing cycles and client audit dates
**Buyer:** Practice leader / VP of Offensive Security
