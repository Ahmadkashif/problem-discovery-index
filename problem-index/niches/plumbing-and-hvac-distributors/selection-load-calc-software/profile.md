# Equipment Selection & Load-Calculation Software Publishers

**Parent Industry:** [[industries/plumbing-and-hvac-distributors|Plumbing & HVAC Distributors]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Publishers of the software that sizes HVAC loads and selects equipment: third-party load-calculation tools that implement ACCA's Manual J and S (Wrightsoft, Elite Software, recalled), and manufacturers' own selection and building-load programs (Carrier's HAP, Trane's TRACE, recalled) that distributors' applications specialists run to re-select a schedule. Licences are sold to contractors, engineers and distributors, or given away by manufacturers.

## Insight Function
**Size:** Software developers and product engineers; there is no research team producing billable analysis (estimate)
**Output:** Software releases, selection and load reports generated by users
**Proprietary data:** Product performance tables (the manufacturers'), weather and design-condition data, and the code that applies ACCA's methods
**Clock:** Product release cycles and catalogue updates after regulatory transitions
**Buyer:** Contractors, engineers and distributor applications managers
