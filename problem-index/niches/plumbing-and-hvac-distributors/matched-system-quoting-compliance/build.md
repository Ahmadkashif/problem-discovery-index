**Industry:** [[industries/plumbing-and-hvac-distributors|Plumbing & HVAC Distributors]]

**Tags:** #large-language-models #k-nearest-neighbors #decision-trees #data-integration #automation #compliance #revenue-impact
**Contested on:** Every serious competitor in this niche is fighting to turn a dealer's replacement call into a priced proposal for a certified, compliant matched system — the right efficiency for the region, an A2L-rated coil and furnace, rebates checked — in one step, and whoever returns the most dealer proposals that need no correction takes the account.

## The Problem
A dealer needs good-better-best options for a 3.5-ton heat pump replacement in a given ZIP code. The inside salesperson finds condensers, matches coils and air handlers in the AHRI directory, checks the regional rule, confirms refrigerant compatibility with an existing furnace, looks up the utility rebate, prices it and emails it back — repeated dozens of times a day in summer.

## Why Nobody Has Built This
Each lookup lives in a different system: AHRI's directory, DOE's rules, OEM catalogues, utility programme lists, the distributor's prices and stock. OEM tools cover one brand; distributors carry several.

## What to Build
A service that takes the dealer's request (tonnage, fuel, ZIP, existing equipment, budget tier), returns ranked compliant matched systems in the house's carried brands with stock, price, rebate eligibility and the paperwork each programme needs, and explains any rule that excluded an option. A two-week demo works on AHRI's public directory data and published regional rules.

## Target Customer
HVAC distributors' dealer-development and digital teams; proposal-software vendors as an API.

## Impact If Built
If an inside salesperson builds ~20–40 system quotes on a peak day at ~10 minutes each (estimate), cutting each to a minute returns most of a day per person in July and removes the compliance misses that come back as rebate denials.
