# Event Production & AV Technical Teams

**Parent Industry:** [[industries/event-planning|Event Planning]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
The technical design groups at event production companies engineer the audio, lighting, staging, and broadcast for large events, producing the plots and technical riders the show is built from.

## Insight Function
**Size:** 5-25 technical designers per production company
**Output:** Technical designs, plots and riders, load and rigging calculations
**Proprietary data:** Accumulated venue-specific technical knowledge
**Clock:** Show dates, absolutely fixed
**Buyer:** Technical Director
