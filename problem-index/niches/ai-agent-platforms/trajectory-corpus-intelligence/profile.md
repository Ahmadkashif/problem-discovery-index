# Trajectory Corpus Intelligence

**Parent Industry:** [[industries/ai-agent-platforms|AI Agent Platforms]]
**Category:** Highly Automatable
**Contested on:** Every serious competitor in this niche is fighting to turn millions of complete task trajectories into empirical answers about where approval belongs, which failures are recoverable and what predicts a task going wrong — and whoever does that sets the standard the category is judged by.

## Profile
**Market Size:** ~$300M US
**Share of Parent Industry:** ~12% of category revenue
**Digital Adoption:** None — used to debug single incidents
**Target Buyer:** The platforms themselves, and their customers as beneficiaries
**Automation Potential:** Very High — the corpus is structured and continuous

## What Makes This a Distinct Niche
The platforms accumulate something the field badly needs: millions of complete task trajectories with the tools called, the state at each step, the outcome and — in the vertical products — whether the customer was satisfied. That corpus answers the questions this category currently settles with intuition: where human approval actually needs to sit, which failures are recoverable and which are not, what predicts a task going wrong before it does, which agent design patterns work for which task shapes, and how much a given change to a prompt or a tool set is really worth. It is currently used to debug individual incidents, which is the least valuable thing it can do.

## Current Tools & Gaps
Trajectory traces for debugging, per-customer dashboards, and incident investigation. The gaps: no cross-deployment analysis of what works; no empirical basis for approval placement; no prediction model despite abundant labelled outcomes; no published account of agent reliability in practice, which the field has no source for; and no feedback from the corpus into product defaults.
