# Software Estimation & Project Benchmarking

**Parent Industry:** [[industries/software-dev-agencies|Software Development Agencies]]
**Category:** Insight Layer
**Value-Chain Position:** Data & benchmark vendors

## What They Do
Maintain the historical project databases and parametric models used to estimate what a software project should cost and how long it should take, and to arbitrate when a delivery goes wrong.

## Insight Function
**Size:** 20-100 estimators, metrics analysts, and researchers
**Output:** Parametric estimates, project benchmarking against historical data, schedule and cost risk analysis, expert opinion in disputes
**Proprietary data:** Multi-decade databases of completed projects with size, effort, duration and defect data — the only empirical record of what software delivery actually takes
**Clock:** Estimation and dispute timelines
**Buyer:** Principal / Chief Scientist
