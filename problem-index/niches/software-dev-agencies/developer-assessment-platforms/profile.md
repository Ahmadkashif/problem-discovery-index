# Technical Talent Assessment Platforms

**Parent Industry:** [[industries/software-dev-agencies|Software Development Agencies]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Test whether a developer can actually write code, at scale, for employers and agencies who cannot interview everyone — the screening layer that determines who gets a technical interview.

## Insight Function
**Size:** 60-300 assessment designers, psychometricians, data scientists, and engineers
**Output:** Coding assessments and question banks, scoring and benchmarking, skills taxonomies, hiring funnel analytics, published developer skills research
**Proprietary data:** Millions of scored code submissions across a global developer population, with hiring funnel outcomes attached for some customers
**Clock:** Hiring cycles
**Buyer:** VP of Data Science / Chief Assessment Officer
