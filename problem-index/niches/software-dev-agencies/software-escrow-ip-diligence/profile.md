# Software Escrow & IP Provenance Services

**Parent Industry:** [[industries/software-dev-agencies|Software Development Agencies]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Hold source code in escrow against a supplier's failure, verify that the deposited material would actually build and run, and audit code provenance and ownership before a transaction.

## Insight Function
**Size:** 30-200 verification engineers, analysts, and legal specialists
**Output:** Escrow deposits and verification reports, build and runtime verification, provenance and ownership audits, release condition administration
**Proprietary data:** Verification findings across thousands of deposits — including how often deposited code cannot actually be built
**Clock:** Contract renewal and release event triggers
**Buyer:** VP of Verification Services
