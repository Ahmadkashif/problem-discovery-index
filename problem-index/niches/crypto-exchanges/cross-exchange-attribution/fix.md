# The Same Address Investigated Everywhere

**Niche:** [[niches/crypto-exchanges/cross-exchange-attribution/profile|Cross-Exchange Attribution]]
**Industry:** [[industries/crypto-exchanges|Crypto Exchanges]]
**Type:** Fix (Pain Point)
**One-liner:** An address flagged at one exchange is investigated independently, from scratch, at every other exchange it touches.
**Tags:** #graph-theory #quick-win #automation #compliance #evaluation-metrics #descriptive-statistics #data-integration #workflow-orchestration
**Contested on:** Every serious competitor in this niche is fighting to turn the identity-to-address junction that exchanges generate into an asset they own rather than one they rent back from a vendor — and whoever organises that first controls the input the whole industry's compliance runs on.

## The Problem
An analyst at one exchange spends an afternoon tracing an address, concludes it is a peer-to-peer trader rather than anything illicit, and closes the case. Two weeks later an analyst at another exchange receives an alert on the same address and repeats the entire afternoon. Across the industry the same few thousand high-traffic addresses are investigated hundreds of times, reaching conclusions nobody shares, at a cost that is entirely duplicated.

## Why It's Still Broken
Sharing conclusions looked like a legal question before it looked like an efficiency one, so it was referred to counsel and stopped there — and no forum existed to restart it. The conclusions are unstructured, written as narratives inside case files. Travel rule channels exist but were scoped narrowly. And nobody measured the duplication, so its scale is unknown.

## What a Fix Looks Like
Record conclusions in a shareable form and start with what is already permitted. Structure every case conclusion — what the address is, how confident, on what evidence — which is the fix and is valuable inside a single exchange before any sharing happens at all. Deduplicate within the exchange first, since the same address is frequently re-investigated internally and that alone recovers real time. Measure the internal repeat rate, which is a single query and will make the external case by analogy. Share exculpatory conclusions first, because clearing an address is the lowest-risk and highest-volume category. Use the travel rule channel that already exists, as it is a sanctioned path for exactly this kind of counterparty information. Attach provenance to any shared conclusion, so a receiving analyst can weigh it rather than inherit it. Never share customer identity, since the conclusion is about the address and that distinction is what keeps this workable. Let conclusions expire, because an address's character changes and a stale clearance is a liability. Route disagreements between exchanges for review, as divergent conclusions on the same address are the most informative signal in the system. And measure duplicated investigation hours, which is the number nobody has and which would settle the argument.

## Who Feels the Pain
Analysts repeating work done elsewhere; compliance functions capacity-limited by duplication; customers investigated at every venue they touch; and an industry paying many times for one conclusion.

## Impact If Fixed
Sharing was referred to counsel as a legal question and no forum existed to restart it as an efficiency one. Structuring conclusions pays off inside a single exchange first, and the travel rule already provides a sanctioned channel for the rest.
