# Medical Coding Content Publishers

**Parent Industry:** [[industries/urgent-care|Urgent Care]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
Publish the code sets, edits and payer policy content that determine whether an urgent care visit is paid and at what level — including the evaluation and management levelling rules that decide the difference between a low and a high reimbursement for the same encounter.

## Insight Function
**Size:** 200-800 coding specialists, clinical editors, and policy analysts
**Output:** Code set content and edits, levelling guidance, payer policy summaries, documentation requirements, compliance reference works
**Proprietary data:** Decades of curated coding interpretation and accumulated payer policy history
**Clock:** Annual code set updates, quarterly edit releases, and continuous payer policy change
**Buyer:** VP of Content / Chief Coding Officer
