# Attribution Modelling

**Parent Industry:** [[industries/revops-consultancies|RevOps Consultancies]]
**Category:** 🔵 High Market Share
**Contested on:** Every serious competitor in this niche is fighting to say which activities produced revenue, using a model whose output nobody has ever checked against a controlled test — and whoever validates it takes the account.

## Profile
**Market Size:** ~$1.2B US
**Share of Parent Industry:** ~20% of category revenue
**Digital Adoption:** Medium, ungraded
**Target Buyer:** Marketing and revenue leadership
**Automation Potential:** High — causal measurement and validation

## What Makes This a Distinct Niche
The attribution model is the second artefact these firms are judged on. It assigns credit for revenue across campaigns, channels and activities, it drives budget allocation, and it is built from touch data using a rule somebody chose. Nobody validates it. The choice between first-touch, last-touch, multi-touch and an algorithmic variant changes the answer substantially, and which one is correct is a testable question that is never tested.

## Current Tools & Gaps
An attribution model in the marketing automation platform or a custom build, and a dashboard nobody disputes out loud. The gaps: no validation against controlled tests; no uncertainty on any attributed figure; no comparison between models; no treatment of unobserved touches; and no measure of how much budget allocation changes with the model choice.
