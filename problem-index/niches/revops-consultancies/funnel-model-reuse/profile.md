# Funnel Model & Reporting Reuse

**Parent Industry:** [[industries/revops-consultancies|RevOps Consultancies]]
**Category:** ⚡ Highly Automatable
**Contested on:** Every serious competitor in this niche is fighting to stop rebuilding the same funnel model, stage definitions and dashboard set for the twentieth time, and whoever packages it takes the account.

## Profile
**Market Size:** ~$0.35B US
**Share of Parent Industry:** ~6% of category revenue
**Digital Adoption:** Low — rebuilt each time
**Target Buyer:** Consultancy delivery
**Automation Potential:** Very high — templates and deployment

## What Makes This a Distinct Niche
A RevOps consultant builds the same funnel model, the same stage definitions and the same dashboard set for the twentieth time, each from scratch, because the last nineteen live in clients' systems. The variation between clients is real and small: the stages have different names, the segments differ, the reporting emphasis shifts. The structure is the same. It is the most repetitive technical work in the discipline and it is done by hand on every engagement.

## Current Tools & Gaps
A previous client's screenshots, a documentation page and a consultant who has done it before. The gaps: no deployable templates; no standard stage definitions to adapt; no dashboard packs; no parameterisation for client variation; and no maintenance as platforms change.
