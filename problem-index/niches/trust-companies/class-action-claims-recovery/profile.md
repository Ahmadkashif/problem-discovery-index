# Securities Class Action Claims Recovery Services

**Parent Industry:** [[industries/trust-companies|Trust Companies]]
**Category:** Insight Layer
**Value-Chain Position:** Suppliers selling into the industry

## What They Do
When a securities class action settles, every institution that traded in the class period may file a claim. Custody banks file for many clients themselves or outsource to specialists — ISS Securities Class Action Services, Financial Recovery Technologies, Broadridge (which won BNP Paribas Securities Services' mandate) — who track cases worldwide, determine eligibility from clients' trading records, calculate recognised losses and file claims, usually for a share of recoveries. Surveys found most institutions relied on their custodians and monitored them little.

## Insight Function
**Size:** ~10-50 case research and eligibility analysts per firm (estimate); claims processing staff are production and not counted
**Output:** Case monitoring, eligibility and loss analyses, filed claims and recoveries
**Proprietary data:** Case and settlement databases built from public filings, plus each client's transaction history supplied by custodians under the service agreement
**Clock:** Court-approved claim filing deadlines in each settlement — hard and third-party
**Buyer:** Head of class action services
