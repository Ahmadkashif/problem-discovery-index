# Phasing Software Taught Berth Windows

**Niche:** [[niches/heavy-civil-contractors/port-marine-structures/profile|Port, Wharf & Marine Structures]]
**Industry:** [[industries/heavy-civil-contractors|Heavy Civil Contractors]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Scheduling and 4D tools sequence any building; a wharf rebuild must also fit the terminal's vessel calls, crane moves and berth-closure limits.
**Tags:** #optimization-fundamentals #dynamic-programming #monte-carlo-methods #workflow-orchestration #data-integration
**Contested on:** Every serious competitor in this niche is fighting to drive, cap and deck wharves, piers and bulkheads while the port keeps ships working at the neighbouring berths, and whoever hands back each berth with the fewest days of closure takes the account.

## The Problem
Terminal operators publish vessel schedules weeks ahead and allow only so many berths out at once. The contractor's phasing plan is redrawn by hand every time a ship call moves.

## What Already Exists
P6 and 4D sequencing tools, terminal operating systems on the port side, and AIS vessel-tracking feeds.

## The Customization Gap
Berth-closure constraints and liquidated damages per berth, crane-barge positions that can't block a moored ship, tide windows for pile caps, and a re-plan triggered by changes in the terminal's vessel schedule.

## Target Customer
Project managers on design-build and CM-at-risk port contracts.

## Impact If Solved
If each phase change is re-planned in hours instead of days (estimate), berth handovers slip less often, which on a contract with daily liquidated damages of ~$10,000–$50,000 (estimate) pays for itself in one avoided week.
