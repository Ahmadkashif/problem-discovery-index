# Managed Repair Programme Administrators

**Parent Industry:** [[industries/public-adjusters|Public Adjusters]]
**Category:** Insight Layer
**Value-Chain Position:** Payer & intermediary layer

## What They Do
Run the carrier-preferred contractor networks that handle property claims end to end — assigning work, reviewing scope and pricing, and guaranteeing the repair. The direct commercial counterparty to a public adjuster, whose case is usually that the programme scope is too narrow.

## Insight Function
**Size:** 200-1,500 estimators, scope reviewers, network managers, and analysts
**Output:** Scope and estimate review, contractor assignment and performance scoring, cycle time and severity analytics, repair guarantees
**Proprietary data:** Claim scope, revision and settlement histories joined to contractor performance across very large volumes
**Clock:** Claim cycle time targets and carrier service level agreements
**Buyer:** VP of Claims Operations / Chief Analytics Officer
