# A Field Nobody Asked For

**Niche:** [[niches/lending-marketplaces/outcome-data-recovery/profile|Outcome Data Recovery]]
**Industry:** [[industries/lending-marketplaces|Lending Marketplaces]]
**Type:** Fix (Pain Point)
**One-liner:** Several lenders would return the decision if asked and have never been asked, because the request has never been on anyone's list.
**Tags:** #quick-win #data-integration #workflow-orchestration #automation #evaluation-metrics #descriptive-statistics #revenue-impact #compliance
**Contested on:** Every serious competitor in this niche is fighting to make returning the decision a condition of participating in the marketplace — and whoever changes that term first gets the feedback loop the whole category has been operating without.

## The Problem
The category treats missing outcome data as a structural fact. In practice it is an unasked question. Some lenders would send a decision flag without much argument — the smaller ones dependent on marketplace volume, the ones already sending funding files, the ones whose own analytics teams would like the matching to improve. Nobody has systematically asked, because the request never appeared on a partner manager's agenda and the ask has no owner.

## Why It's Still Broken
Partner managers are measured on volume and bid rates, so a data request is not on the agenda and does not help their number — the incentive simply points elsewhere. The technical ask is not specified, so a willing lender has nothing concrete to implement. Nobody has quantified what the data is worth, which means it cannot be traded for. And the assumption that lenders will refuse has never been tested.

## What a Fix Looks Like
Ask, with a specification attached. Write the ask down as a concrete minimal field set with an integration guide, which is the fix and turns a vague request into a two-hour task for a willing partner. Put it on every partner review agenda, since the conversations already happen quarterly and the request costs nothing to raise. Start with the lenders most dependent on marketplace volume, because they have the most reason to agree. Offer something specific in return — ranking preference, a segment report, reduced unqualified volume — as an ask with no offer is easy to decline. Record who was asked and what they said, which is the first time anyone will know the real refusal rate. Accept partial data gladly, since a decision flag without terms is still transformative compared to nothing. Make it a standard clause in new and renewing contracts, as that is where the change compounds without a renegotiation. Show early adopters the improvement in their own lead quality, because that is the evidence that moves the rest. Quantify the value internally so it can be traded against bid rates, which is the currency partner managers actually have. And give the effort an owner, since a request that belongs to everybody belongs to nobody.

## Who Feels the Pain
Data teams working without the signal; partner managers arguing lead quality without evidence; lenders receiving mismatched volume; and borrowers routed on clicks.

## Impact If Fixed
The incentive points at volume and bid rates, so the request never reached an agenda. A written field specification raised in reviews that already happen tests an assumption the category has never checked.
