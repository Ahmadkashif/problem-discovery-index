# Preparer Errors & Omissions Underwriting

**Parent Industry:** [[industries/tax-prep-firms|Tax Preparation Firms]]
**Category:** Insight Layer
**Value-Chain Position:** Payer & intermediary layer

## What They Do
Underwrite the professional liability and accuracy guarantee programmes preparers and software providers offer, and pay the penalties and interest when a return turns out to be wrong.

## Insight Function
**Size:** 20-100 underwriters, claims analysts, and actuaries
**Output:** Programme pricing, claims adjudication, accuracy guarantee reserving, error pattern analysis
**Proprietary data:** Claims recording exactly which return positions turned out to be wrong and what it cost
**Clock:** Season-driven claim emergence following notices
**Buyer:** Programme Underwriting Manager
