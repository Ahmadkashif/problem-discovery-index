# Faithful Synthesis Across Vendors

**Niche:** [[niches/expert-networks/cross-call-synthesis/profile|Cross-Call Synthesis]]
**Industry:** [[industries/expert-networks|Expert Networks]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** Each network summarises its own calls, and the client's evidence is spread across four of them.
**Tags:** #large-language-models #transformers #word-embeddings #evaluation-metrics #ai-platform #workflow-orchestration
**Contested on:** Every serious competitor in this niche is fighting to be the layer that turns all of a client's calls and library transcripts into a faithful, cited synthesis — and whoever is trusted not to invent a quote wins the research workflow above the calls.

## The Problem
Clients use several networks and libraries in one project. Each vendor's AI features see only its own transcripts.

## Why Nobody Has Built This
Every vendor wants the synthesis layer on its own content; cross-vendor ingestion requires the client to own it.

## What to Build
A client-owned synthesis layer that ingests transcripts from every source, extracts claims with line-level citations, verifies each citation automatically, and maps agreement across sources.

## Target Customer
Research operations at funds and consultancies.

## Impact If Built
Puts the synthesis where the evidence is complete, which is the client's side.
