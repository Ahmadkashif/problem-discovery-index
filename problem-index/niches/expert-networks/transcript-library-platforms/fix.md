# The Call Host's Question Plan Lives in Their Head

**Niche:** [[niches/expert-networks/transcript-library-platforms/profile|Transcript Library Platforms]]
**Industry:** [[industries/expert-networks|Expert Networks]]
**Type:** Fix (Pain Point)
**One-liner:** The library's best call hosts know which questions draw out specifics from a particular kind of expert, and every new host learns it by running weak calls that become permanent catalogue entries.
**Tags:** #tacit-knowledge-ml #large-language-models #k-nearest-neighbors #evaluation-metrics #worker-facing #quick-win

## The Problem
Analyst-hosted calls are the library's production line. An experienced host knows how to move a former executive from generalities to numbers, which follow-ups expose that an expert is guessing, and which topics a given role will actually know. A weak call — vague, leading, or off the subscriber-demand topic — is published anyway and stays in the catalogue, read less and trusted less.

## Why It's Still Broken
Hosts work to a calls-per-week target. Call quality is judged informally by editors, and the link between question technique and subscriber reads has never been measured.

## What a Fix Looks Like
Score hosted calls on specificity (numbers, dates, named decisions per minute), subscriber reads and dwell, and later claim accuracy. Mine the top hosts' transcripts for question sequences by expert type and topic, and give new hosts a pre-call question plan with the closest high-performing prior calls retrieved. Review a weekly sample with senior hosts to calibrate the specificity measure against their judgement.

## Who Feels the Pain
New call hosts learning on the live catalogue; subscribers reading weak calls; the platform, whose catalogue quality is set by its least experienced hosts.

## Impact If Fixed
Each hosted call is a permanent asset. Raising the floor of call quality raises the value of every future read of it, at no extra call cost.
