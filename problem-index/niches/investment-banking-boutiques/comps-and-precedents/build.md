# Precedents With Provenance

**Niche:** [[niches/investment-banking-boutiques/comps-and-precedents/profile|Comps & Precedents]]
**Industry:** [[industries/investment-banking-boutiques|Investment Banking Boutiques]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** Half the multiples in a mid-market precedent table were never disclosed, and nobody records which half or where the estimates came from.
**Tags:** #linear-regression #gradient-boosting #confidence-intervals #feature-engineering #data-integration #evaluation-metrics
**Contested on:** Every serious competitor in this niche is fighting to produce a peer set and precedent range for a private mid-market target that an informed buyer would accept as the right benchmark — and whoever does that with provenance on every multiple becomes the default valuation page.

## The Problem
Precedent tables mix disclosed figures with estimates from press, colleagues and the firm's own deals.

## Why Nobody Has Built This
Provenance is invisible on the page, and the firm's own deal multiples carry confidentiality limits.

## What to Build
A precedent library recording source, confidence and permitted use for every multiple, with model-estimated ranges for undisclosed deals and explicit intervals, and display rules that respect confidentiality.

## Target Customer
Boutiques' research and valuation teams.

## Impact If Built
Consistent, defensible valuation pages and a growing proprietary precedent asset.
