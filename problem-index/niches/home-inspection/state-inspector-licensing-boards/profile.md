# State Inspector Licensing Boards

**Parent Industry:** [[industries/home-inspection|Home Inspection]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
State boards license home inspectors where licensing exists, set continuing education requirements, and handle consumer complaints against inspectors.

## Insight Function
**Size:** 2-10 licensing and investigation staff per state
**Output:** Licensing decisions, complaint findings, disciplinary actions
**Proprietary data:** Complaint records by inspector
**Clock:** Licence renewal cycles
**Buyer:** No commercial buyer
