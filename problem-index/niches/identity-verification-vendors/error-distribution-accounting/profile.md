# Error Distribution Accounting

**Parent Industry:** [[industries/identity-verification-vendors|Identity Verification Vendors]]
**Category:** ⚡ Highly Automatable
**Contested on:** Every serious competitor in this niche is fighting to be the first to publish how its error rates are distributed across the populations it decides about — and whoever produces that number defines the standard everyone else is then measured against.

## Profile
**Market Size:** ~$550M US
**Share of Parent Industry:** ~9% of category revenue
**Digital Adoption:** Very Low — nobody publishes it
**Target Buyer:** Data and policy leadership
**Automation Potential:** Very High — the data exists and the method is routine

## What Makes This a Distinct Niche
Every vendor holds document images, match scores, outcomes and retry behaviour at enormous volume. Computing how error rates vary by document type, device, capture condition, file depth, tenure and the demographic groupings that public evaluations already report is technically routine. Nobody does it publicly. The contest is not technical — it is whether a vendor will produce a number that is uncomfortable, and the first one to do so sets the terms for the whole category.

## Current Tools & Gaps
Internal dashboards, pass rates and occasional vendor-commissioned assessments. The gaps: no disaggregated error reporting; rejection outcomes not obtained; subgroup sample sizes not addressed; methodology not standardised; and no independent verification.
