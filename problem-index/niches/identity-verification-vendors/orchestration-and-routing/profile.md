# Orchestration & Routing

**Parent Industry:** [[industries/identity-verification-vendors|Identity Verification Vendors]]
**Category:** 🔵 High Market Share
**Contested on:** Every serious competitor in this niche is fighting to send each applicant to the verification path that will actually verify them — and whoever measures which path works for which kind of person owns the decision layer above every individual vendor.

## Profile
**Market Size:** ~$1.0B US
**Share of Parent Industry:** ~17% of category revenue
**Digital Adoption:** Medium — routing by hand-written rules
**Target Buyer:** Platform and policy leadership
**Automation Potential:** Very High — routing as a learned decision

## What Makes This a Distinct Niche
Customers now stack several verification vendors behind routing rules: this document type to that vendor, this geography to another, fall back to a third on failure. The rules are written by hand, based on vendor claims and anecdote, and nobody measures which path actually verifies which kind of applicant. Whoever can answer that sits above the individual vendors and controls the decision, which is why the orchestration layer is the category's most strategically contested position.

## Current Tools & Gaps
Orchestration platforms, rule builders, vendor connectors and waterfall fallbacks. The gaps: routing not learned from outcomes; per-vendor performance by applicant type unmeasured; cascade cost and latency unmanaged; fallback paths untested; and no attribution of a failure to the path that caused it.
