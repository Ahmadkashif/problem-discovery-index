# Document & Geography Coverage

**Parent Industry:** [[industries/identity-verification-vendors|Identity Verification Vendors]]
**Category:** 🟠 Low Digitized
**Contested on:** Every serious competitor in this niche is fighting to support thousands of document types across hundreds of jurisdictions, each with its own layout, security features and revision history — and whoever stops maintaining that library by hand supports the documents everyone else declines.

## Profile
**Market Size:** ~$750M US
**Share of Parent Industry:** ~13% of category revenue
**Digital Adoption:** Low — templates maintained manually
**Target Buyer:** Coverage and operations leadership
**Automation Potential:** High — generalisation and change detection

## What Makes This a Distinct Niche
Every jurisdiction issues identity documents, revises them periodically, and keeps older versions in circulation for a decade. Each revision has its own layout, fonts, security features and data encoding. The template library that lets a system read and validate them is maintained by hand, one document at a time, and a document not in the library is either rejected or read badly. Coverage determines who the product can serve, and it is a manual production problem.

## Current Tools & Gaps
Template libraries, specimen collections, jurisdiction research and manual template authoring. The gaps: no generalisation to unseen documents; new revisions discovered when failures spike; coverage not reported honestly; older revisions deprioritised; and no measure of which missing documents cost the most.
