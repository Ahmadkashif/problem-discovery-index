# The Virtual First Hire

**Niche:** [[niches/interior-design-firms/solo-design-studios/profile|Solo & Two-Person Studios]]
**Industry:** [[industries/interior-design-firms|Interior Design Firms]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** A solo designer's first hire is almost always a design assistant who handles orders, samples, invoices and client follow-ups, and that role can increasingly be done by software that acts rather than records.
**Tags:** #large-language-models #transformers #survival-analysis #workflow-orchestration #automation #worker-facing #revenue-impact
**Contested on:** Every serious competitor in this niche is fighting to let a one-person studio run procurement, billing and client communication without its first hire, and whoever replaces that first assistant takes the account.

## The Problem
Studio software for small firms stores proposals and orders but waits to be told what to do. The owner still writes every PO email, chases every vendor, sends every invoice and answers every client question. The work a first assistant would take over is exactly the work the tools leave to the owner.

## Why Nobody Has Built This
Until recently, software could not read a vendor acknowledgement, judge whether a client message is an approval, or draft a credible chase email. Studio-software vendors have built record systems for larger firms first.

## What to Build
An agent that runs the assistant's checklist: places orders from approved proposals, reads acknowledgements and flags mismatches, chases quiet vendors, orders samples, logs client approvals from texts and emails, drafts invoices with correct tax, and sends the owner a daily list of the few decisions only they can make.

## Target Customer
Solo and two-person residential studios with three to eight active projects.

## Impact If Built
The owner takes on one or two more projects a year without payroll, or keeps the same load and gets evenings back; the cost is a fraction of an assistant's salary.
