# Knowing Which Ideas Are Worth Making

**Niche:** [[niches/performance-marketing-agencies/concept-selection/profile|Concept Selection & Prediction]]
**Industry:** [[industries/performance-marketing-agencies|Performance Marketing Agencies]]
**Type:** Build (Greenfield Opportunity)
**One-liner:** The tools that generate creative volume have no idea which concepts are worth producing, and the agency chooses on taste and a test budget.
**Tags:** #gradient-boosting #transformers #contrastive-learning #causal-inference #confidence-intervals #evaluation-metrics #revenue-impact #bayesian-inference
**Contested on:** Every serious competitor in this niche is fighting to know which concepts are worth producing before the money is spent — and whoever builds that prediction from a portfolio of creative and its measured performance owns the one advantage a platform cannot supply.

## The Problem
A strategist proposes six concepts for a campaign. Three get produced, based on which the room liked. Two of the three fail in market, which is discovered after production cost and test spend. The agency has run this process for four hundred clients over a decade and has no accumulated view of which kinds of concepts work for which kinds of brand, because the outcome data was never joined to a description of the creative and the engagement ended before anyone looked. Every campaign begins with the same six-concept meeting and the same taste-based selection.

## Why Nobody Has Built This
Creative performance was never recorded in a form that could be learned from, which is the data model problem the parent niche's fix note addresses and is the practical blocker. Cross-client learning requires the agency to treat its portfolio as an asset rather than as a set of engagements, which is an organisational change. Predicting creative performance questions the judgement of senior people, which is politically difficult inside agencies. And the confounding is real — good concepts get more budget — so a careless version produces findings that are obviously wrong and discredits the effort.

## What to Build
Predict at the concept stage. Represent the concept structurally — angle, claim type, opening device, format, talent, emotional register, offer — extracted automatically from the asset, which is the input and is now reliably obtainable. Model performance against that representation with the confounding handled, since budget, audience and timing move with creative choice and naive attribution will credit the concept for the budget it received. Pool across the agency's portfolio, which is where the statistical power is and is the only asset in this category that a platform cannot replicate. Condition on brand and category, because a concept that works for a challenger brand may fail for an incumbent and an unconditioned finding is useless. Predict before production so the selection meeting has evidence in it, which is the entire point — a prediction after launch is a report. Rank the proposed concepts with intervals, since the honest output is a ranking with uncertainty rather than a winner. Identify what is untested rather than only what is predicted, because a portfolio of safe concepts will never find the next thing and deliberate exploration should be budgeted. Feed predictions into briefing so production is directed. Report calibration openly to the creative team, since credibility with them determines whether the system is used at all. And measure against the taste baseline, because that comparison is the claim and creative teams will rightly demand it.

## Target Customer
Performance and creative agencies, in-house performance teams, and the brands whose creative selection is a meeting.

## Impact If Built
A decade of four hundred clients produced no accumulated view because outcomes were never joined to a description of the creative. Pooling a structural representation across the portfolio, with the budget confounding handled, is the one advantage a platform cannot supply.
