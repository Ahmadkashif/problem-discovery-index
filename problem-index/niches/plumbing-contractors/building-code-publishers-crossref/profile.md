# Plumbing Code Development & Publication

**Parent Industry:** [[industries/plumbing-contractors|Plumbing Contractors]]
**Category:** Insight Layer
**Value-Chain Position:** Regulatory & enforcement bodies

## What They Do
Develop and publish the model plumbing codes that jurisdictions adopt into law, run the consensus development process behind them, and produce the commentaries, training and certification the enforcement community works from.

## Insight Function
**Size:** 200-600 code development staff, technical committees, editors, and training personnel
**Output:** Model codes and standards, commentaries and interpretations, adoption tracking, inspector certification and training
**Proprietary data:** The code development record — proposals, testimony, committee reasoning and interpretation history — accumulated over decades
**Clock:** Triennial code cycles and jurisdiction adoption calendars
**Buyer:** Chief Technical Officer / VP of Codes
