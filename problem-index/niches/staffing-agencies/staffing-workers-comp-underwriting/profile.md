# Staffing Workers' Compensation Underwriting

**Parent Industry:** [[industries/staffing-agencies|Staffing Agencies]]
**Category:** Insight Layer
**Value-Chain Position:** Payer & intermediary layer

## What They Do
Underwrite workers' compensation for staffing firms — a class where the insurer covers workers it never sees, performing tasks at client sites it does not control, and where a single misclassified assignment can produce a catastrophic loss.

## Insight Function
**Size:** 100-600 underwriters, actuaries, claims analysts, and risk control consultants
**Output:** Programme pricing and eligibility, class code assignment and audit, claims management, client site risk assessment, loss control requirements
**Proprietary data:** Claims joined to assignment type, client industry, worker tenure and site — the only systematic record of what actually injures temporary workers
**Clock:** Annual renewals, payroll audits, and continuous claim reporting
**Buyer:** Chief Underwriting Officer
