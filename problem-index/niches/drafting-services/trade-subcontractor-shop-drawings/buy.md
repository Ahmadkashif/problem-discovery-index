# Cabinet Software Adapted to Architectural Submittals

**Niche:** [[niches/drafting-services/trade-subcontractor-shop-drawings/profile|Trade Subcontractor Shop Drawings]]
**Industry:** [[industries/drafting-services|Drafting Services]]
**Type:** Buy & Customize (Vertical Adaptation)
**One-liner:** Casework software already drives the CNC router from a cabinet model; it was not built to produce the elevations, sections and notes an architect reviews.
**Tags:** #decision-trees #large-language-models #automation #workflow-orchestration #quick-win
**Contested on:** Every serious competitor in this niche is fighting to get a small trade subcontractor's shop drawings approved on the first submittal inside the general contractor's submittal schedule, and whoever turns architect comments into a clean resubmittal fastest takes the subcontractor's repeat work.

## The Problem
Millwork shops model cabinets for production, then redraw the same work as submittal shop drawings in AutoCAD because the production output is not what architects review.

## What Already Exists
Cabinet Vision and Microvellum model casework and generate cut lists and CNC programs; both produce some drawings.

## The Customization Gap
The adaptation needs: submittal-format sheets (elevations keyed to the architect's plan, sections, hardware schedules) generated from the production model; the project's specification requirements and AWI grade carried as notes; architect comments mapped back to model changes; and resubmittal clouds generated automatically.

## Target Customer
Architectural woodwork shops already using casework software, and the drafting bureaus that serve them.

## Impact If Solved
One model for submittal and production, eliminating the redraw and the inconsistencies between approved drawings and what the shop builds.
