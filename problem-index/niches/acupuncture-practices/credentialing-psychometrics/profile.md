# Acupuncture Credentialing & Psychometrics Units

**Parent Industry:** [[industries/acupuncture-practices|Acupuncture Practices]]
**Category:** Insight Layer
**Value-Chain Position:** Association research arms

## What They Do
The certification bodies that define and test professional competence — principally NCCAOM, with state boards licensing off its examinations. Staff and contracted psychometricians run the job task analysis that defines the scope of practice, write and calibrate exam items, set cut scores, and defend the whole apparatus at NCCA re-accreditation.

## Insight Function
**Size:** 10-30 including contracted psychometricians
**Output:** Job task analysis reports, exam blueprints, technical reports on item performance
**Proprietary data:** Decades of item response data and candidate performance across cohorts and schools
**Clock:** Examination administration windows and the NCCA re-accreditation cycle
**Buyer:** Director of Certification / Chief Credentialing Officer
