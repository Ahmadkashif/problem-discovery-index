# The Lumber Package Only the Estimator Can Build

**Industry:** [[building-material-dealers|Building Material Dealers]]
**Type:** High Impact
**One-liner:** A dealer prices every house from an incomplete plan set through an estimator's judgement, records the job's add-on loads and returns that grade that judgement, and never joins the two, so the skill that wins bids is neither measured nor kept.
**Tags:** #tacit-knowledge-ml #object-detection #cnns #large-language-models #gradient-boosting #evaluation-metrics #revenue-impact #workflow-orchestration

## The Problem
A custom builder in a growing county emails three dealers the same plan set on a Tuesday: four sheets of floor plans and elevations from a home designer, a window schedule, a one-line note that says "trusses by supplier," no framing plan and no structural sheet. Each dealer's estimator has to turn it into a framing package — wall plates and studs by height, headers and beams for every opening, floor system, sheathing, roof framing or a truss order, engineered lumber, hardware, wrap and fasteners — at a waste factor, priced against this week's lumber market, and returned before the builder picks a supplier. Remodelers send hand sketches and phone photos. Production builders send a new plan and expect a per-house price that will hold across a year of starts.

The skill in this is mostly what isn't drawn. The experienced estimator knows that this designer never shows point loads, so the girder truss and the beam under it will be needed; that this framer builds with ladder blocking and double top plates and wants 16-foot plates rather than 12s; that the builder's "standard" deck ledger is always pressure-treated 2x10; that 9-foot walls in this county mean precut studs and a different header height; that the bay window will need a cripple package nobody drew. They know which builders change the plan in month two and which framers waste. Newer estimators price the drawings, and a typical takeoff from scratch takes an experienced estimator ~1–4 hours (estimate), with queues of several days in spring.

The outcome of every takeoff is recorded in detail and never used. Every add-on ("fill-in") order when the framer runs short, every return when the yard over-shipped, every back-charge and every second truck sits in the ERP against the job account. The ERP can say that a package of ~$40,000–$80,000 (estimate) grew by ~5–15% (estimate) in add-ons. It cannot say whether the takeoff missed it, the framer wasted it, the builder changed the plan or it walked off the site. So the dealer cannot tell which estimators are accurate, which builders need a contingency, or what the veteran knows that the junior doesn't. When the veteran retires, the dealer keeps the job history and loses the judgement.

## Why It's Unsolved
The data collection problem is that the estimator's reasoning has to be captured while they work, inside takeoff screens and spreadsheets that store the finished list and nothing else. The assumptions — "added girder, designer omits point loads," "used 16s, framer preference" — are never typed, because typing them is a tax on the busiest person in the yard. And the drawings themselves are the hard input: residential plan sets are inconsistent, often scanned, and rarely contain the framing information a model would need, so the model has to infer exactly what the estimator infers.

The labelling problem is that the job's net consumption is a noisy label. Delivered quantity minus returns plus add-ons measures what the job took, not what it should have taken: framers waste, builders change plans, materials disappear from open sites, and returns are not always recorded. Experts disagree with themselves too: the same estimator applies a ~10% waste factor in winter and ~7% in a bid war (estimate), and two estimators take off the same plan to totals several percent apart. An honest label needs plan revisions tracked and a re-takeoff sample to measure agreement before any model is called accurate.

The deployment problem is speed and trust. A builder chooses a supplier partly on turnaround, so assistance must return a draft faster than the estimator can start one, show which sheet and which assumption each line comes from, and leave the estimator in control, because a missed beam is the estimator's name on a change order. Tools that produce a confident list the estimator then has to re-check line by line save nothing.

## What a Solution Looks Like
A takeoff ledger first and a model second. Every package is drafted from the plan set by sheet reading (walls, openings, dimensions, roof geometry, schedules) and a deterministic framing generator, then edited by the estimator; every edit is stored with a one-click reason. When the job closes, the ledger joins the package to delivered, returned and add-on quantities from the ERP and to any plan revisions, so each line's error can be attributed to takeoff, plan change or site waste.

On top of the ledger, learn the estimators' adjustments. A model trained on edits and outcomes predicts what this builder, framer, designer and region will need beyond what is drawn — girders, blocking, longer plates, waste by category — and attaches its evidence. It runs as a draft on intake, not a verdict, and its first value is speed: a priced draft in minutes from a plan set, which is also the owner's two-week MVP shape (a public permit-portal plan set in, a priced lumber list against a synthetic dealer price file out). The emailed list a framer has already written belongs to the cross-distribution intake field at [[niches/industrial-distributors/rfq-and-order-intake-automation/profile|RFQ & Order Intake Automation]]; this problem is the plan set nobody has listed yet, the analogue of [[niches/electrical-distributors/bid-day-project-quoting/profile|Bid-Day Project Quoting & Takeoff]] in electrical distribution.

## Impact If Solved
If a draft cuts an experienced estimator's takeoff from ~2 hours to ~30 minutes of review (estimate), a yard with three estimators can answer several times as many bids in the spring queue, and a dealer that cuts add-on deliveries by even a third saves a truck run and a phone call on a large share of its jobs. Keeping the veteran's adjustments as a model with a track record turns retirement from a loss of judgement into a handover, and gives the trade its first measured view of takeoff accuracy.
